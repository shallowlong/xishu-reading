### 1. Monotype 单版油印 · 一次成印的「幽灵印」
- **来源**：Tate《Monotype》词条 https://www.tate.org.uk/art/art-terms/m/monotype ｜ Tate《Monoprint》词条 https://www.tate.org.uk/art/art-terms/m/monoprint ｜ Britannica《Monotype》 https://www.britannica.com/topic/monotype-printmaking ｜ Civitai `PZNS Monotype Style v2 — Grammar` https://civitai.com/models/2926202 ｜ `PZNS Monotype Style v2 — Surface` https://civitai.com/models/2927676
- **标签**：版画 / 油画 / 重颗粒
- **一句话特征**：一块被擦洗过的光滑金属板上糊着一层薄墨，纸上压出来的是**大片晕开的墨洗**（不是线条）、亮部是被布擦回去的纸白、满版盖着一层**半调网点颗粒**，纸边是**撕裂的毛边**，画上还留着**龟裂、金缮裂纹和霉斑**。
- **为什么有意思**：
  - **它是版画里唯一「不能版画」的那一种**。铜版、凸版、平版、丝网——所有版画的定义就是「同一块版可以反复印出很多张」，而 monotype 是把油墨或油彩直接**画在一块光滑的玻璃或金属板上**（没有刻痕、没有母版），纸压上去一次，图像就转移到纸上了，板上的墨也随之耗尽。
  - **反直觉：印完还能再印，但第二张是「鬼」。** Tate 词条明写第一张抽走后板上剩的墨**通常不足以再做一张**，除非重新补墨；硬要再压，得到的是一张淡得多、性格完全不同的 **ghost print（幽灵印 / cognate）**。有些画家故意把这张鬼印当第二件作品来经营——一张印刷品天生带一张自己的影子。
  - **反直觉：它是「最像油画的版画」，因为它其实是绘画。** Castiglione（1610–65）最早在铜版上试，Blake 与 Degas（19 世纪）把它当成油画的替身——Degas 那些著名的**暗场单版印（dark-field monotype）**是全版铺满黑墨、再用破布和笔杆把光「擦」出来，所以整幅的重心是**减法**：亮部不是画上去的，是**擦掉的**。Britannica 特别强调它「因独特的肌理质感而受珍视」，正是因为每张的肌理都不可能复现。
  - **技法来源**：加法（additive，用刷子辊子手指把墨铺上板）与减法（subtractive，整版铺满墨再用布、刷、木条擦出亮部）两法；湿纸比干纸多约 10% 的调子范围；压印用凹版印刷机或手工 burnishing。
  - **社区冷门度实测**：Civitai 上 `monotype` 只有 **5 件**，且其中 4 件是同一位摄影家兼版画家（作者自称 professional photographer and printmaker）的 **PZNS 双 LoRA 体系**——`pzns_style`（构图层：flat ink washes + engraving-style hatching + halftone grain + torn plate edges，强度 0.8–1.0，CFG 3.5–4.5）与 `pzns_texture`（材质层：craquelure、golden kintsugi cracks、foxing、fold creases、torn raw plate edges，强度 0.9–1.1，可做 img2img 收尾层）。作者明确写了「商用需经作者许可」，**别拿去直接上架卖货**。
  - **与库里近邻的错开**：vs 11-20 Wood Engraving 白线木口雕版（那是凸版，靠**刻**出白线，版是永久母版）——本条版上**没有任何刻痕**，图像完全活在墨层里；vs 09-11 Mezzotint（凹版靠滚磨出丝绒黑，版也是永久母版）；vs 10-10 Posada 骷髅版画（黑白排线的凸版）；vs 09-23 Cliché-verre 玻璃版画（那是**真的**在玻璃上刻，线是磨出来的）。本条是「擦出来的墨」，不在那一条线上。

  - **其他工具**：
    - **Nano Banana / Gemini Image**：适合描述「先做一张再转印」的两步逻辑——直接说「把这张图处理成单版油印的质感：暗部墨洗、亮部擦除、满版半调网点、撕裂毛边」。它对「减法」指令理解较好，适合把干净摄影稿转成这条。
    - **GPT Image**：擅长描述「物理痕迹」类细节，craquelure / torn deckle / kintsugi line 这类词可换成更口语的表述（如「纸面像被火烧过的旧纸，有细密龟裂，右下角有一道金线修补痕迹」）。
    - **Recraft / Ideogram**：这两家更偏矢量与海报，做这条要**显式要求写实纸感**，否则出扁平插画；若只用它们，建议改成「用这个风格画一张**版画海报**」的降级用法，把 halftone grain 换成「粗网点半调」更稳。
    - **Adobe Firefly**：出图偏「干净插画」，这条用它出成功率最低，**建议直接跳过**。
- **避坑**：
  - **人脸崩**：这一条人物母题最容易崩——因为 monotype 靠墨层造型，模型一遇到脸就会往「清晰的写实素描」跑，此时墨洗、网点、毛边全丢，只剩一个普通铅笔稿。**解法：把人物放在画面里但压到次要位置，或干脆换静物 / 手部 / 布料褶皱这类不依赖五官的主体**；脸部只要「暗示」不要「交代」。
  - **材质丢失**：最容易出现的是「版画感」退化成「复古海报感」——边缘变干净、网点消失、纸面变新。**排查关键词：torn deckle edge、halftone grain、craquelure 三个缺一个就说明跑偏了**。
  - **与其它版画混淆**：出成规整的蚀刻线稿 = 母版思维污染；出成木刻黑白 = 凸版污染。负向里必须写死。
  - **过度「做旧」**：craquelure / foxing / kintsugi 三样同时上过量会变成「仿古滤镜套餐」，反而假。**每样只留一两处**，尤其 kintsugi 线**只画一条**。
  - **颜色溢出**：如果主体是彩色物件，模型会把物件颜色渗进整幅墨层，破坏单色调。负向加 `saturated colors, rainbow`。
- **可选 · 服装/童装用法**：单版油印那套「**大面积素色底 + 满版细网点 + 一处不规则破口**」的结构，本身就是童装印花里最好用的「不靠图案靠肌理」的满印方案——比如给纯色卫衣做一版「洗旧了的墨洗 + 局部网点掉色」，成本几乎为零（一个丝网版 + 破坏性做旧处理），观感却比满版印花高级。也可以只取「一版独印」的**唯一性**做亲子装：同一块布上印两版几乎一致但不完全一样的图案，模拟手作感。

### 2. Delftware 荷兰代尔夫特锡釉蓝陶
- **来源**：Seattle Art Museum《Tripod bowl with cover》藏品条目 https://art.seattleartmuseum.org/objects/12836/tripod-bowl-with-cover ｜ Minneapolis Institute of Art 藏品《Vase, one of a pair, 17th century》 https://linkedculture.org/q/q1.e0byATu-J5dJ8VE-.dxY6kQoZCdmTQPl7LWWx0EkE5YT-9RKXH_QhTje0QIEV_hDZr1PZIAVCdRwcH4UUuNuLE4P7lG6w8sd9ccLnVyucYIuiAwG1_fzkpaBbVuY4he8EZ9W4ELXYr90U_-7i51mxheCf9Px25Bj4eIzdyz-QXOSdCdYqmbS2le3WMDfbYSLQ ｜ Historic Jamestowne《Delft Tiles》 https://dev.historicjamestowne.org/?p=39412 ｜ Civitai `Made of Delftware AI` https://civitai.com/models/140179
- **标签**：陶瓷 / 织物
- **一句话特征**：**奶白不透明的锡釉底**上，**钴蓝手绘**的帆船、塔亭与长袍人物，花卉纹边框带铁红与锰紫，笔触**粗细不匀、边缘发毛**，釉面爬满**细密开片**，个别小缺口露出底下**淡黄陶胎**。
- **为什么有意思**：
  - **它是一场「仿制失败」变成「原产地」的经典案例**：1609 年荷兰东印度公司开始大量进口中国青花瓷，**薄胎、半透明、釉下钴蓝**——欧洲此前完全没见过这种材质。但荷兰陶匠**造不出瓷**（要 1300℃ 高温，而当时欧洲的窑只能到 1100–1200℃），于是改用**低温陶胎 + 锡釉**去「模仿」：低温烧成多孔胎体 → 浸入加了**氧化锡**的液体锡釉 → 干后变成不透明白 → 用钴蓝手绘 → **再高温烧一次**把颜色和釉熔合。
  - **反直觉：所谓「荷兰青花」，底层逻辑是「我们做不出中国瓷，只能拿釉去装得像」**。结果 Delftware 在 17 世纪成了欧洲最有名的瓷器替代品，**Delft 这个地名本身变成了一个品类词**（Jamestowne 档案明确记载：荷兰产的写大写 Delft，英国产的写小写 delft）。更狠的是，Delft **本来是啤酒城**——Seattle Art Museum 的藏品说明写着，17 世纪初该城近 200 家啤酒厂因竞争关闭，**厂房被陶厂接手，连厂名都沿用了酒厂名**（De Pauew 孔雀、De Drie Klokken 三钟、三座镀金酒桶）。一座城的产业是被另一种产业吃掉的。
  - **反直觉：连轮廓都是「用针孔印出来的」**：Delft 瓷砖（壁炉饰砖）的图案流程是**先用针在纸样上扎出许多小孔（pounce / spons）→ 铺纸样 → 用炭粉拍打 → 炭粉透过针孔落到釉面上留下淡淡轮廓 → 画师照着炭痕手绘上色**。也就是说欧洲最著名的「中国风」纹样，最初的骨架是一台**手工的点阵印刷机**。
  - **锡釉不是「白瓷」，是「不透明白」**：这是它与真正的中国青花最要命的差别，也是它的辨识度来源——**釉像牛奶一样厚且完全不透光**，钴蓝画在釉面上而不是釉下，所以笔触边缘会**吸釉发毛**、颜色会**在笔痕里积深**，跟玻璃质青花那种锐利干净的线完全不同。
  - **技法来源**：锡釉（铅釉 + 氧化锡 → 不透明白地）+ 钴蓝 + 高温二次烧成 + 针孔转印（pounce）+ 铁红/锰紫/锑黄三种矿彩；裂纹是釉与胎收缩不同步造成的**釉裂（craquelure）**，小缺口露出的淡黄胎说明它确实是**陶器不是瓷器**。
  - **社区冷门度实测**：Civitai 上 `delftware` **只有 1 件**（`Made of Delftware AI`，SD 1.5，作者自己写「works best at 0.6 to 1.0 for a more wild look」，并且建议把颜色写进括号里如 `(blue)` 才出效果）；`delft` 与 `faience` 查询同样只命中这一件；而 `tin glaze`、`blue pottery` 全被「锡人/蓝壶」类无关件和二次元角色 LoRA 污染。→ **社区先验极低，本条必须纯正向写死 + 可选挂那 1 件并限权**。
  - **与库里近邻的错开**：vs 10-26 Iznik 伊兹尼克（奥斯曼釉下彩瓷，石英胎 + 钴蓝/青绿/番茄红 + 透明铅釉，釉下彩所以颜色封在釉里）——本条是**锡釉 + 釉上/二次烧**，白地是**锡的不透明**不是胎的白；vs 汝窑天青釉（单色青釉 + 蟹爪纹开片 + 芝麻钉）——本条是**蓝白彩绘陶**，开片只是附带的釉裂不是主体；vs 10-04 Lusterware（金属膜二次低温还原烧出的虹彩光泽）；vs 10-13 螺钿（珍珠层）；vs 10-01 Fordite（汽车漆层压石）。**「白底蓝花」这个母题在库里还没被占，但必须写死「不透明白的锡釉」和「钴蓝画在釉面」，否则模型会给中国青花或日式十 cords 蓝染**。
- **通用提示词**：

### 3. Mamluk Gilded & Enamelled Glass 马穆鲁克镀金珐琅玻璃
- **来源**：Victoria and Albert Museum《Mosque lamp》藏品 O808 https://collections.vam.ac.uk/item/O808/mosque-lamp ｜ V&A《Bottle》藏品 O813 https://collections.vam.ac.uk/item/O813/bottle-unknown/ ｜ Discover Islamic Art《Mosque lamp》（V&A 藏） https://islamicart.museumwnf.org/database_item.php?id=object;ISL;uk;Mus02;43;en ｜ Discover Islamic Art《Bottle》 https://islamicart.museumwnf.org/database_item.php?id=object;ISL;uk;Mus02;15;pt ｜ Civitai `Damask (mamluk decorated vases style)` https://civitai.com/models/986956
- **标签**：玻璃 / 高对比 / 装饰艺术
- **一句话特征**：**透明玻璃**器身上，**不透明珐琅彩**堆出**钴蓝地 + 红色勾边 + 金色卷草**，一圈**蓝色阿拉伯书法带**被三个**圆形徽章**隔开，徽章里是**凤凰与狮鹫**；**交织纹的内部刻意留空**，让器物自身的火光从镂空处透出来。
- **为什么有意思**：
  - **反直觉：这是一件「靠光才成立」的作品**。V&A 藏品页原文：灯身那套精细交织纹样**只勾红轮廓、内部留空**，所以**点灯时这些纹样会发光**——图案本身就是用「什么都没画」的部分构成的。这是把「负空间」当成发光器件用的古代工艺，比任何现代镂空灯早七百年。
  - **反直觉：它是「借来的中国元素」**：马穆鲁克是蒙古人政权，但器物上的**凤凰（Chinese-style phoenix）与中国龙**是当时皇家权力的象征——**丝绸之路把中国的图像带进了伊斯兰宫廷**，然后被工匠重新组织进阿拉伯书法与卷草的框架里。V&A 明确记载凤凰与龙「在马穆鲁克人中成为王权的流行符号」。
  - **反直觉：它是被「编号」的历史**：V&A 那盏灯上写着对苏丹 **Barquq（1382–1399 在位）** 的颂词，馆方记载**存世 59 盏同批灯**：25 盏在开罗伊斯兰艺术博物馆、22 盏在开罗伊玛目侯赛因清真寺、12 盏散落世界各处。**你今天看到的每一件，都是当年宫廷订单的一个零件**，编号能对上号。
  - **反直觉：它曾经是「批量生产的量产品」**：V&A 藏瓶页直说——珐琅玻璃工业**是「为一个买得起的富人阶层做量产」的产业**（the glass industry was one of mass-production for a wealthy elite）。所以「一件中世纪手工艺术品」的直觉印象其实是错的，它更像 19 世纪的工厂瓷器，只是材料换成玻璃。
  - **技法来源**：吹制无色玻璃 → 描金（gilding）→ 低温珐琅彩绘（钴蓝 / 宝石红 / 白 / 绿）→ 低温焙烧使珐琅熔附；苏丹颂词用 **thuluth（苏鲁斯体）** 书法；纹样母题是**交错带状卷草（islimi）**；鎏金是在玻璃表面烧附的金叶。珐琅是不透明的，所以**必须靠「留空」才能透光**——这条的视觉机制全靠这个矛盾。
  - **社区冷门度实测**：Civitai 上 `mamluk` 相关只有 **1 件**：`Damask (mamluk decorated vases style)`（Flux.1 D），作者说它是从「玻璃与珐琅质感的马穆鲁克花瓶」里抽出来的泛化风格，README 明确写了**要出效果必须配合 `islamic calligraphy` / `islamic ornate decor` / `arabic` 之类关键词，并把权重提到 1.4 以上**。同时 `champleve`（錾花珐琅）查询 **0 命中**、`kufic`（库法体）**0 命中**——社区先验极低，本条必须**纯正向写死 + 关键词强化**。
  - **与库里近邻的错开**：vs 10-04 Champlevé 錾花凹陷珐琅（**金属胎**，凹处填釉）——本条是**玻璃胎 + 表面画釉 + 描金**；vs 09-09 Cloisonné 掐丝珐琅（金属胎掐丝填釉）——本条**没有掐丝**，是手绘珐琅；vs 10-13 螺钿（珍珠层薄膜干涉）/ 10-27 曜变天目（黑釉金属膜）——本条是**冷色调不透明釉层压在透明玻璃上**；vs 10-29 Fordite（汽车漆层压石）——层压但材料与机制全不同；vs 10-13 Roman Cameo Glass（套料玻璃纵向减雕）——本条是**表面附加**，不是减材雕刻。**「伊斯兰纹样」这个母题在库里尚未被占**，但必须靠**材质对比（透明玻璃 vs 不透明珐琅）+ 鎏金 + 书法带**这三个硬特征撑住，否则会滑成普通的伊斯兰风纹样。

## 本期附记

- **冷门度实测方法沿用并再次验证**：Civitai 官网直连超时，但 `civitai.red/api/v1/models?query=` 这条 API 路径完全可通，可同时拿到 id / baseModels / trainedWords / README 全文。**查冷门度必须用专有名词**——本期 `champleve` 与 `kufic` 全部 0 命中（干净可用），而 `mamluk` / `delftware` / `monotype` 各只有 1–5 件（真正的冷门）；反例同样明显：`enamel` 命中 15 件里大半是二次元角色 LoRA，`tin glaze` 命中的全是「锡人/绿野仙踪」。
- **母题**：这三条共享一个内核——**「工艺里的『缺陷』才是它的签名」**。Monotype 的第一张印完板就废、只剩一张鬼印；Delftware 的锡釉画不出瓷、只能装得像；马穆鲁克珐琅不透明、要靠留空才能透光。**三者都不是「做得更完美」的作品，是「被工艺逼出特定样子」的作品**——这恰好也是为什么它们在参数堆砌的 AI 生图里特别难被复现：模型追求的是完美，而这三条的美，全在那个不完美的地方。
- **三条的 SD LoRA 现实**：Monotype 有成熟的双 LoRA 体系（但作者明写商用需许可）；Delftware 只有 1 件 SD1.5 老件；Mamluk 只有 1 件 Flux 件且需权重 1.4+。**共同点是都不好用，所以纯正向写死才是正解**，LoRA 只当加分项。
