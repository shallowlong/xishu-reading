### 1. Pixel Sorting 像素排序（数据熔流 / 故障光带）

- **来源**：Modulate「Pixel sorting」技法页 + Toolcroft / Studio-ity 实操工具页（真实 URL）
  - https://modulate.to/effects/pixel-sort
  - https://filmfreebies.com/pixel-sorting.php
  - https://studio-ity.com/pixelsort
- **标签**：视觉技法：流体 ／ 情绪质感：高对比、重颗粒
- **一句话特征**：画面像被「排序」过一遍——高亮区被抽出来按明度重新排成平滑的**光带瀑布**，光带边缘是**条形码般锐利的像素断点**，暗部锚在原处；整幅图的颜色直方图其实**一点没变**，只是像素换了个位置。
- **为什么有意思**：这是「数据 glitch art」里极少数**有算法定义**的一条，不是「加噪 + 位移」那种随手糊。技法源头是 **Kim Asendorf 2010 年的 Processing 脚本 ASDFPixelSort**（第 1015 行 modulate 原文明确给了出生点）：它沿每一行/列扫描，把「亮度高于阈值的连续像素串」单独拎出来，按**明度 / 色相 / 饱和度**之一重排。关键在它的**置换性质（permutation）**——不新增不删除任何像素，所以传感器原本的颗粒会**原封不动地活在那条光带内部**，光带尽头的像素边界是**像素级锐利**的（在阈值翻转的那一格突然切断）。这正是它和「方向性动态模糊」的分水岭：模糊是新混出颜色把一切抹匀，像素排序只是搬家具，纹理是画面自己的。冷门在「把『排序』这个信息论动作用到照片像素上」——反直觉到多数人以为是糊的。命中「被遗忘的数字艺术运动（glitch / data mosh 系）」。
- **通用提示词**：
```
vertical pixel sorting glitch, the brightest pixels of the image detached and dripping downward into luminous streaks,
barcode-crisp streak ends, hue-sorted rainbow bands, sensor grain preserved inside each streak,
no directional motion blur, glitch art, ASDF pixel-sort aesthetic, dark background
```
- **效果图参考**（agnes-image-2.5-flash，2K / 1:1）：![Pixel Sorting 像素排序](https://pic1.imgdb.cn/i/034tqwRnlLD8JEndDGfy1k.webp)
- **分工具适配**：
  - **Midjourney**：
    ```
    vertical pixel sorting glitch, bright pixels dripping into luminous downward streaks, barcode-crisp streak edges, hue-sorted rainbow bands, sensor grain inside the streaks, glitch art, ASDF pixel sort aesthetic --s 150 --ar 3:4 --style raw
    ```
    参数说明：`--s 150`（识别度建立在**高密度光带细节**上，中高档；太高会被模型加戏成纯抽象色块）；`--style raw`（压制 MJ 的自动美化，保留"脏"的 glitch 质感）；`--ar 3:4`（竖排水滴要纵向空间）。
  - **即梦**（中文）：
    ```
    竖排像素排序故障艺术，画面最亮的像素被抽离向下融化成光带，光带边缘如条形码般锐利，色相排序的彩虹条带，
    光带内部保留传感器颗粒，无方向性动态模糊，故障艺术，深色背景
    ```
    按即梦「艺术风格 + 主体描述 + 文字排版」句式；名词堆叠、逗号谨慎（第三方封装下逗号可能截断，可用顿号）。`sample_strength`/`ratio`/`resolution` 待验证（见参数复核备忘，来自第三方封装，非官方）。
  - **Stable Diffusion（SDXL / SD3.5）**：
    - 正向：`vertical pixel sorting glitch art, luminous downward streaks, barcode-crisp streak ends, hue-sorted rainbow bands, sensor grain preserved inside streaks, high contrast, dark background`
    - 负向：`directional motion blur, uniform soft blur, added noise, color histogram shift, smooth gradient, over-sharpened, 3D render, photorealistic smooth`
    - LoRA 建议：Civitai 若有 `pixel sort` / `glitch art` / `datamosh` 类 LoRA 可叠加 0.5–0.7（**本期 civitai 通道不稳未实测**，见备忘；不确定就纯靠上面向向 + 负向写死，不要硬塞 LoRA 文件名）。
  - **Flux.1（Black Forest Labs）**（国际补充）：
    ```
    vertical pixel sorting glitch: the brightest pixels detach and drip downward into smooth luminous streaks with
    barcode-crisp ends, hue-sorted rainbow bands, sensor grain inside the streaks, glitch art, ASDF pixel sort
    ```
    Flux 对自然语言长描述友好，直接给整句。
- **避坑**：
  1. **最大的坑是「AI 根本做不到严格置换」**——真正的像素排序是像素总数不变，模型是「重新画」，所以只会**近似**出 streak 质感，别指望数学上真的 permutation。验收只看「有没有融化的光带 + 条形码锐利边缘 + 光带里有颗粒」三件。
  2. **光带被糊成动态模糊**：一出现"上下均匀拖影"就是模型动了方向性模糊，命中负向即翻车。务必正向写死 `barcode-crisp` 与 `no directional motion blur`。
  3. **颜色溢出**：hue-sort（色相排序）容易把彩虹拉过饱和，肤色会被洗成霓虹，人脸基本废——这条风格**不适合出人脸**，出景物/抽象/纹理。
- **可选 · 服装/童装用法**：竖排水滴光带天生 Y2K/潮牌感，适合做**童装运动外套或卫衣侧边的「数据熔流」数码印花**——把一件平铺的外套侧面喂给它，光带从上往下淌，很抓眼。

### 2. Stereograph 维多利亚双幅立体卡（穷人的画馆）

- **来源**：V&A「Stereographs」工艺史 + University of Louisville 立体卡特藏 + 国家科技媒体博物馆博客（真实 URL）
  - https://www.vam.ac.uk/blog/factory-presents/stereographs
  - https://library.louisville.edu/archives/stereographic-views/about-stereographs
  - https://blog.scienceandmediamuseum.org.uk/a-z-photography-l-is-for-london-stereoscopic-company
- **标签**：媒介：胶片 ／ 工艺：湿版（蛋白银印相）／ 情绪质感：褪色、低饱和
- **一句话特征**：一张**厚米色卡纸**上并排印着**两张几乎一样的画面**，**棕调蛋白银相**质地、四角带轻微晕边，卡纸下方一行**印刷小字号目录编号**，整张要夹进双镜立体镜、两张图相隔约 7cm（人眼瞳距）才会「立体」起来。
- **为什么有意思**：这是**人类历史上第一种"量产"的摄影品**，不是后来才有的——19 世纪中期（1850s 前后）就已经开邮购、开连锁、有"6,000–12,000 位立体摄影师 / 至少 500 万张"（Louisville 特藏引 William Culp Darrah），被点名叫作**「the first visual mass media」和「poor man's picture gallery」（穷人的画馆，1858 年《泰晤士报》语）**。它反直觉的地方在**「观演必须隔 7cm 才成立」**：画面本身是双幅的、平的、甚至有点重影，只有当两张图的分量差**恰好等于你的瞳距**、再凑到两个镜片前，大脑才会把「平面双图」捏成**一张立体景深图**——画面的"第三维"不在画面里，在**你两只眼的间距**里。技法来源极硬：Wheatstone 1838 用镜反射发明立体镜、Brewster 1844/1850 换棱镜做成"封闭盒"（20 世纪 View-Master 的直系祖宗）、Oliver Wendell Holmes 1859 造出手持式并写下「我们用眼睛抱住一个物体，就像用手臂、用手抱住它」（V&A 原文）。冷门在「双幅并置 + 卡纸 + 编号」这套**今天几乎绝迹的载体外壳**。命中「复古媒介复活 + 物理观演装置」。
- **通用提示词**：
```
Victorian stereograph card: two nearly-identical photographs printed side by side on a thick cream card mount,
sepia-toned albumen silver print, faint vignetting at the corners, a small printed catalogue number beneath the image,
faded, hand-tinted, the very first mass-produced photography of the 1850s, soft antique paper texture
```
- **效果图参考**（agnes-image-2.5-flash，2K / 1:1）：![Stereograph 维多利亚双幅立体卡](https://pic1.imgdb.cn/i/034tqub1KLDPM0pXjYUOxc.webp)
- **分工具适配**：
  - **Midjourney**：
    ```
    Victorian stereograph card, two nearly-identical side-by-side views spaced for a stereoscope, thick cream card mount, sepia albumen silver print, faint vignetting, small printed catalogue number beneath, hand-tinted, faded, first mass-produced photography 1850s --s 80 --ar 3:2 --style raw
    ```
    参数说明：`--s 80`（识别度全在**极简结构**上——双幅 + 卡纸 + 编号 + 棕调，四样东西，stylize 一高模型就把它脑补成"两张现代照片"）；`--ar 3:2`（横卡）；`--style raw` 保留脏旧纸感。
  - **可灵 / Kolors**（中文）：
    ```
    维多利亚立体卡片，厚米色卡纸上并排印着两张几乎相同的画面，供双镜立体镜观看，棕调蛋白银印相，四角轻微晕边，
    画面下方一行印刷目录小编号，手工上色，褪色，1850 年代首批量产摄影，柔和旧纸质感
    ```
    可图 Kolors 支持 `negative_prompt`/`guidance_scale`（默认 5）/`num_inference_steps`（默认 30）/`aspect_ratio`（历史实检值，本次未复核）。
  - **Stable Diffusion（SDXL / SD3.5）**：
    - 正向：`Victorian stereograph card, two nearly-identical photographs side by side on a cream card mount, sepia albumen silver print, faint vignetting, small printed catalogue number beneath, hand-tinted, faded antique paper, 1850s photography`
    - 负向：`modern digital photo, single centered image, flat color, glossy, HDR, 3D, lenticular flip, cartoon, high saturation, clean scan`
    - LoRA 建议：`sepia` / `vintage` / `albumen` 类 LoRA 可叠加；**本期未实测**，不确定就纯正向写死"双幅 + 卡纸 + 棕调蛋白 + 编号"四要素，别指望通用模型真的自动排成双幅——**构图指令（side by side / two views）必须写死**，否则 9 次里 7 次给你一张居中的单图。
  - **GPT Image（OpenAI）**（国际补充）：
    ```
    A flat lay of a Victorian stereograph card: two nearly-identical sepia albumen photographs printed side by side
    on a thick cream card mount, faint corner vignetting, a small printed catalogue number beneath, hand-tinted,
    faded antique paper, soft warm light, photographed from above
    ```
    GPT Image 吃自然语言长句，重点把"side by side / two views"这个双幅约束写满。
- **避坑**：
  1. **最致命：模型不出双幅**——「并排两张几乎一样的图」是这条的灵魂，绝大多数模型默认给一张居中单图。**正向务必写死 `two nearly-identical photographs side by side`**，出完先数几张。
  2. **两幅差太多**：真实立体卡两幅只差约 7cm 视差，模型容易把左右画成**两个完全不同场景**（左雪山右教堂）——要「几乎相同」，不是「两张不同图」。
  3. **棕调溢出成糊**：sepia 一给重就整张发死发黄，控制 `faded` 而非 `dark sepia`，纸边留米色不压黑。
  4. **编号小字糊成一团**：目录编号是这条的"可信度锚点"，但 AI 出小字基本必糊，**别指望能读字**，只看"有一行印刷小字"的形态即可。
- **（服装/童装联想不自然，本条省略）**

### 3. Rotoscoping 铅笔转描（活动描针 / 看着真其实是画）

- **来源**：communityvfx 转描史 + encyclopedia.com 弗莱舍条目 + TaggedWiki「Rotoscoping」完整技术史（真实 URL）
  - https://communityvfx.blogspot.com/2008/12/rotoscoping.html
  - https://www.encyclopedia.com/node/558104
  - http://taggedwiki.zubiaga.org/new_content/321944c3f8ef473ec233d0d2a1b0ccab
- **标签**：媒介：3D（赛璐珞 / 手绘）／ 工艺：丝网印（平涂实色）／ 情绪质感：高对比
- **一句话特征**：动作**真实得像真人拍的**（因为底下垫的就是真人逐格投影），但**线条是干净的手绘铅笔线 + 平涂色块**——一张「看着像照片那么真、其实一笔一笔描出来」的错位静帧。
- **为什么有意思**：这条 09-28 起留档了**整整三期**，是稀有「Civitai 上有大量现成 LoRA 可以直接打」的类型，今天消化掉。技法来源是整个动画工艺里**最硬的一条线**：Max Fleischer 把真人（他弟弟 Dave 扮小丑）的动作**逐格投到磨砂玻璃上**、再用纸一笔笔描，1917 年拿下**活动描针（rotoscope）专利**；Koko the Clown 是头一个转描角色，1930 年代 Betty Boop 的 Cab Calloway 舞步、1937《白雪公主》（迪士尼也用了）、1985 a-ha《Take On Me》、2001《Waking Life》/2006《A Scanner Darkly》（Linklater 数字插值转描）一路传到今天（TaggedWiki 技术史）。反直觉的点在**「动作逼真」和「手绘线条」这对矛盾体被焊死在同一帧**：它看着比真人还流畅，是因为**底下就是真人**，可整幅又是**平涂赛璐珞 + 干净铅笔线**——「真实感来自实拍，画面却是纯画」这个错位，正是 1930「橡胶管（rubber-hose）」时代的味道（Koko / 早期 Popeye）。命中「反直觉跨界 + 被遗忘的技术 + 早期动画美术」。
- **通用提示词**：
```
rotoscoped animation still, clean hand-drawn pencil outlines tracing realistic live-action human motion,
flat cel color, early 1930s Fleischer Koko the Clown rubber-hose look, hand-drawn keyframes with lifelike movement,
a-ha "Take On Me" / A Scanner Darkly style, no 3D, no smooth vector lines
```
- **效果图参考**（agnes-image-2.5-flash，2K / 3:4）：![Rotoscoping 铅笔转描](https://pic1.imgdb.cn/i/034tquoBulY7mr5UP34k7y.webp)
- **分工具适配**：
  - **Midjourney**：
    ```
    rotoscoped animation still, clean hand-drawn pencil outlines tracing realistic live-action motion, flat cel color, early 1930s Fleischer Koko the Clown rubber-hose look, hand-drawn keyframes with lifelike movement, Take On Me style --s 100 --ar 1:1 --style raw
    ```
    参数说明：`--s 100`（中低档——识别度在「干净线条 + 照片级动作」的**错位**上，stylize 一高就变风格化插画，把"看着真"那层洗掉）；`--style raw`。
  - **通义万相（V2）**（中文）：
    ```
    铅笔转描动画静帧，干净铅笔线条描摹真实真人动作，平涂赛璐珞色块，1930 年代弗莱舍《墨汁井里》Koko 小丑橡皮管风格，
    手绘关键帧带生命感动作，a-ha《Take On Me》风格，无 3D，无平滑矢量线
    ```
    本条按**万相 V2** 写（支持 `negative_prompt` + `prompt_extend`，阿里云官方确认；`size` 档位待验证）。
  - **Stable Diffusion（SDXL / SD3.5）**：
    - 正向：`rotoscoped animation still, clean pencil line over live-action motion, flat cel color, early 1930s Fleischer Koko rubber-hose look, hand-drawn keyframes, lifelike movement`
    - 负向：`3D render, smooth vector lines, photorealistic, realistic shading, high detail texture, CGI, gradient, modern animation, glossy`
    - LoRA 建议（**本期有现成件，重点**）：Civitai 上有 **5 个现成转描 LoRA**（历史实检 id `1176303` / `978704` / `58322` / `878679` / `1015839`，含 Flux / WAN 版），叠加 **0.6–0.8**。这是全库少有的「不用手写、直接打」的一条。若当日搜不到，就退回到上面正向 + 负向写死。
  - **Ideogram**（国际补充）：
    ```
    A rotoscoped 1930s animation still: clean hand-drawn pencil outlines tracing realistic live-action human movement,
    flat cel color, Fleischer Koko the Clown rubber-hose look, hand-drawn keyframes, no 3D, no smooth vector lines
    ```
    若这帧要出带字版（老动画海报/标题卡），Ideogram 的文字渲染最稳。
- **避坑**：
  1. **最要命：模型把「动作真实」丢掉变成普通卡通**——一旦出成「线条圆润、动作随意」的当代动画感，这条就废了。正向必须写死 `tracing realistic live-action motion / lifelike movement`。
  2. **线条被画成平滑矢量**——转描的灵魂是**手抖的铅笔线**（早期是纸笔描，不是矢量），出现「完全平滑、无断点的线」就是模型偷偷走了矢量，命中负向 `smooth vector lines`。
  3. **加戏成 3D / 照片**：一出现写实光影渐变、皮肤高光，就从「平涂赛璐珞」滑进「照片」，命中 `flat cel color / no realistic shading`。
  4. **rubber-hose 比例别拉太夸张**：橡皮管手臂可以，但拉成「手臂长过身体」会跑偏成卡通丑。
- **可选 · 服装/童装用法**：转描天然吃「跑 / 跳 / 摆姿势」的**真人动作定帧**，做**童装运动系列（跑步、踢球、跳跃）的主视觉**特别对味——拍一组孩子动的照片，转描定关键动作，动作真、画风却是手绘，很适合「活力但不假」的运动童装。

## 参数复核备忘（沿用历史实检，本次未新查工具参数）

- **Midjourney**：按官方 Parameter List 惯例，参数放提示词末尾、前留一空格、参数内不得有标点。本期 `--s` 给 **150 / 80 / 100**（第 9 次验证「同一期内 stylize 必须按各自翻车机制分别定值，不能统一」：像素排序=高密度细节→中高档；立体卡=极简结构约束→低档；转描=错位质感→中低档）。`--style raw` 三条全用。
- **即梦**：`negative_prompt` / `sample_strength` / `ratio` / `resolution` 来自第三方封装项目，**官方未确认，标「待验证」**，正文不写死映射。
- **可图 Kolors / 通义万相 V2 / Seedream**：沿用 09-29/09-30 官方实检值；万相明确标「本条按 V2 写」。
- **Civitai 冷门度本期通道不稳**（400 / TLS 超时），**未做实测**；Rotoscoping 现成件数据用 **09-28/09-29 历史实检的 5 个 id**（可信，已交叉验证过），Pixel Sorting / Stereograph 的 LoRA 一律标「未实测，不确定就靠正向写死，不编造文件名」。
