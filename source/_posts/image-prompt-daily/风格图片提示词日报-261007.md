### 1. 内画鼻烟壶（正视反画 · **图是从瓶内壁顶出来的不是贴在瓶外的** · 画师把弯钩笔从直径 0.5cm 的壶口伸进壶内、在「内壁」反向落笔，观众从「外壁」看画面才是正的 · 内壁先灌金刚砂/铁砂加水摇磨成乳白磨砂面、颜料像墨染宣纸一样晕开 · 京冀鲁粤四大流派（衡水＝中国内画之乡、王习三自创金属杆「习三弯勾笔」）· 极费目力、画半小时须休息 · 2008 列入第二批国家级非遗 · Civitai 专有名词本期未实测）

- **来源**：搜狐《非遗印象丨瓶中岁月,袖里乾坤——内画鼻烟壶》 https://www.sohu.com/a/284321560_632483 ；雅昌《鼻烟壶:小中见大 精妙入微》 https://m-news.artron.net/20201222/n692422.html ；企业家日报《壶小乾坤大》（王习三弯勾笔、口径 0.5cm） https://www.entrepreneurdaily.cn/2015-04-29/12/2196030.html
- **标签**：织物 / 微距 / 地域文化
- **一句话特征**：一层乳白磨砂的透明水晶瓶里，内壁上一幅水墨山水／仕女像是「从反面向正面顶出来的」，颜料因磨砂内壁而晕开如墨落宣纸，边缘有一圈磨砂与透光的交界，从外壁正视角看，画面在磨砂层后若隐若现、如梦似幻。
- **为什么有意思**：**反向作画（正视反画）**是全部辨识度的来源——普通玻璃画（如广州玻璃画）是用油画颜料在玻璃**背面**画、画笔空间不受限；内画是把弯钩笔从**黄豆大小**的壶口**伸进瓶腔**、在**内壁**上反向描绘，你眼睛看到的正像，实际是画师在另一面倒着画的。叠加**金刚砂涮膛（串膛）**：内壁本光滑不着色，要先灌金刚砂/铁砂加水反复摇磨成乳白磨砂面，颜料落上去才会像墨染宣纸一样**晕开**——通透朦胧感是磨出来的不是画的。再叠加**目力损耗**这一工艺细节（画半小时须休息、每两小时闭目养神）。京冀鲁粤四派里**衡水冀派**规模最大（王习三金属杆「习三弯勾笔」），鲁派用瓷釉烘烧、粤派艳丽——同一瓶身、四种笔墨。
- **通用提示词**：

```
透明水晶鼻烟壶，壶口仅黄豆大小，内壁以金刚砂磨砂处理成乳白色半透明磨砂面，
内壁用变形弯钩笔反向绘制的中国水墨山水画面（画面是"从反面向正面顶出"的镜像构图），
颜料在磨砂内壁晕染如墨落宣纸、边缘朦胧通透，从外壁正视角观看，
壶体透光、内壁磨砂乳白、画面在磨砂层后若隐若现，古典雅致，工笔皴染细腻
```

### 2. 缂丝 Kesi / 刻丝（通经断纬 · **图案边缘有"刀刻般的透缝"——纬线遇不同颜色就截断、只局部织入，纹样与素地接合处留缝透光，对光看像雕镂浮雕** · 一寸缂丝一寸金 / 织中之圣 / 一衣终岁方成 · 定州→苏州，2006 国家级非遗、2009 UNESCO 人类非遗 · 西方缂织更早（埃及亚麻缂织物 3000 年前），汉晋丝路传入 · 庄绰《鸡肋编》原典 · Civitai 专有名词本期未实测）

- **来源**：苏州非遗信息网《苏州缂丝织造技艺》（编号 GJ-01-Ⅷ-365） https://szfy.wglj.suzhou.com.cn/fy-project/10 ；中国日报网《缂丝成古装剧"主角"》（含庄绰《鸡肋编》原典） https://ent.chinadaily.com.cn/a/202111/23/WS619c535ba3107be4979f9755.html
- **标签**：织物 / 微距 / 地域文化
- **一句话特征**：一块真丝织品，图案的**边缘有透空的缝隙**——因为纬线（彩色丝）遇到不同颜色就**截断**、只用局部小梭子织那一段（「变一色换一梭」），纹样与素地（无花纹处）接合处经线之间**留缝透光**，对着光看像被镂刻过，故称「刻丝」。
- **为什么有意思**：**通经断纬**是全库最反直觉的织造逻辑——普通织物（锦缎/妆花）的纬线是**贯穿整个幅面**的，而缂丝**只织需要那一色的一段**，遇到换色就「先留其处、回头再织」，等于**一块织布里藏着几百次「断+接」**。代价是极端贵（「一寸缂丝一寸金」「如妇人一衣，终岁方成」），收益是**任意图案自由组合**（织一百朵花也不会重复），所以它有「织画」能力，宋元以来是宫廷临摹书画的载体。再叠加**承空透光（承空观之如雕镂之象）**：因为留缝，纹样边缘对光就像雕镂浮雕——**立体感不是织出来的，是「不透」出来的**。源流上比织锦还早（埃及亚麻缂织物 3000 年前、汉晋丝路传入），庄绰《鸡肋编》留了完整织造原典。
- **通用提示词**：

```
丝绸缂丝（刻丝）织物，通经断纬，彩色纬线遇不同颜色即截断、分块分段用局部小梭织入，
纹样与素地接合处留有透空缝隙，对光看如雕镂浮雕（承空观之），
色阶细腻、图案任意组合不重复，古朴典雅，织中之圣质感，
微距可见经丝细、彩纬粗、只显彩纬不露底经，一寸缂丝一寸金
```
- **效果图参考**（agnes-image-2.5-flash，2K / 1:1）：![缂丝 Kesi / 刻丝](https://pic1.imgdb.cn/i/034tr5T1COiC76yRHFDBwp.webp)
- **分工具适配**：

  - **Midjourney**（英文）：

    ```
    Kesi (kesi / ke-si) Chinese silk tapestry, through-warp-interrupted-weft weaving, the weft yarn is cut and re-woven in small local blocks wherever the color changes, gaps and pores at the pattern edges that glow like carved openwork when backlit, dense multi-color silk each color a separate shuttle, antique court silk, macro shows thin warp / thick weft, --s 150 --style raw --ar 3:4
    ```

    参数说明：`--s 150`（中高档——辨识全在「分色分块+边缘透缝+对光雕镂」的**高密度细节**上，需更高 stylize 让织纹读出来）；`--style raw`；`--ar 3:4`。

  - **即梦 Jimeng**（中文，官方 2.1 模板）：

    ```
    国风工笔，丝绸缂丝织物，通经断纬，彩纬遇色截断分块织入，纹样边缘透空如雕镂，色阶细腻古朴，一寸缂丝一寸金，微距见经细纬粗
    ```

  - **可灵 Kolors**（`guidance_scale` 4–8）：

    ```
    缂丝丝绸织物，通经断纬，彩纬分块截断织入，纹样边缘透空缝隙如雕镂，对光承空观之，色阶细腻，古朴
    ```

  - **通义万相 V2**（本条按 V2 写）：

    ```
    正面：丝绸缂丝织物，通经断纬，彩纬遇色截断分块织入，纹样边缘透空缝隙，对光如雕镂浮雕，色阶细腻古朴，微距经细纬粗
    negative_prompt：普通丝绸印花、贯穿纬线的锦缎、妆花、云锦、均匀密织、模糊
    ```

  - **Seedream 4.0 火山方舟**（官方指南：词源语言、双引号文字）：

    ```

    the weft cut and re-woven per color block, openwork gaps at pattern edges glow like carving when backlit,
    dense multi-color silk, 2K
    ```

  - **Stable Diffusion**：
    - 正向：`Kesi kesik (interrupted-weft) Chinese silk tapestry, weft cut per color block, openwork gaps at pattern edges, glowing like carved openwork when backlit, dense multicolor silk, antique, thin warp thick weft, macro, detailed texture`
    - 负向：`satin print, through-weft jacquard, brocade, 妆花, uniform weave, blurry, plastic, modern fabric, text`
    - LoRA 建议：缂丝专有名词（`kesi` / `interrupted weft`）本期未实测命中，**纯靠正向写死**；可选借「silk / silk texture」近亲件限权 0.3–0.5，**必须**在正向写死「cut weft / openwork gaps」，否则模型退化成普通织锦。

- **避坑**：① 模型最易画成**普通丝绸印花/织锦**（纬线贯穿的锦缎）——须写死「遇色截断＋边缘透空缝隙」这个**雕镂感**，是它和云锦/妆花的唯一分野；② **透光要写光源方向**（「backlit / 承空观」），否则透缝读不出来；③ 微距下「经细纬粗、只显彩纬」的比例要写；④ 「分色分块不连片」是灵魂，删了就成均匀密织。
- **可选 · 服装/童装用法**：缂丝「分色分块、不连片、边缘透气针孔」的织造逻辑，可直接做**童装外套的面料拼接设计**——不同色面料交界处刻意留**透气针孔缝**（断纬转译），比平接更有「手工织进」的质感，适合秋装外套/马甲的分色拼接。

### 3. 脱胎漆器 / 夹纻（去胎留漆 · **造型是"把内胎掏掉、只留麻布与大漆的壳"留下来的——器壁仅数毫米厚、轻到可浮于水面，表面是天然大漆（漆树汁液）反复髹涂研磨出的镜面黑红/朱红，内空外光、扣之声轻韧** · 战国起源、东晋戴逵创立生漆夹纻、唐代盛于佛像（行像/脱空像）、清乾隆福州沈绍安恢复「脱胎」髹饰 · 「以柔克刚」东方造物哲学 · 中国工艺美术学会 2026-05 新文 · 与 10-02 犀皮漆（Xipi，研磨断纹）不同：本条是胎骨结构/去胎逻辑，非表面研磨 · Civitai 专有名词本期未实测）

- **来源**：宁波鄞州区政府《脱胎工艺》 https://www.nbyz.gov.cn/art/2013/1/26/art_1229622377_59177852.html ；中国工艺美术学会《赏读 | 脱胎漆艺、轻如蝉翼,韧而耐久的东方造物哲学》（2026-05） https://m.cnacs.net.cn/19/202605/8175.html ；快懂百科《脱胎造像技艺》 https://www.baike.com/wikiid/4058762819711585770
- **标签**：陶瓷 / 玻璃 / 高对比
- **一句话特征**：一件漆器**轻到能浮在水面**，器壁只有**数毫米厚**，表面是天然大漆反复髹涂研磨出的**镜面般黑红/朱红**，内空外光、敲起来轻而韧——造型是「把泥胎/木胎掏掉、只留麻布与漆层壳」留下的，表面有多层纤维纹理暗示它是「裱布+髹漆」叠出来的。
- **为什么有意思**：**去胎留漆（脱胎夹纻）**是这条的命门——普通漆器是「先做实心胎骨再髹漆」，脱胎是**先有胎（泥/石膏/木）→ 生漆裱夏布（苎麻）逐层 → 阴干后掏空内胎 → 只剩麻布+大漆的壳体**。也就是说**「造型」这个看似最实的东西，其实是「掏空」出来的**：你看到的壳越轻越薄，越证明内胎被去掉了。再叠加**大漆材料学**：漆树汁液天生耐酸耐腐耐潮、千年不腐（与铜器/瓷器并称中国传统「三宝」），反复「裱布—刮灰—髹漆—打磨」几十上百道工序，器壁厚到数毫米仍坚固柔韧。历史线：战国见、东晋戴逵生漆夹纻、唐代佛行像（脱空像/行像）、清乾隆福州沈绍安恢复「脱胎」髹饰（2006 福州脱胎漆器髹饰技艺首批国家级非遗）。「以柔克刚、内敛绵长」是它被反复书写的造物哲学。
- **通用提示词**：

```
脱胎漆器（夹纻），器壁仅数毫米厚、轻到可浮于水面，表面以天然大漆（漆树汁液）反复髹涂研磨至镜面般黑红/朱红，
内空外光、扣之声轻韧，器型是"去除泥胎/木胎、仅留麻布与大漆层壳"留下的，
表面可见多层纤维纹理暗示麻布+漆层叠合，千年不腐质感，东方造物以柔克刚，静物棚拍侧光显漆光温润
```
- **效果图参考**（agnes-image-2.5-flash，2K / 1:1）：![脱胎漆器 / 夹纻](https://pic1.imgdb.cn/i/034tr7Ri9hYWv7LREOfJFM.webp)
- **分工具适配**：

  - **Midjourney**（英文）：

    ```
    detaching-the-core (tuotai / jia-zhu) Chinese lacquerware, the inner clay/wood core has been removed leaving only a shell of layered ramie cloth and raw tree-resin lacquer, walls only millimeters thin and light enough to float on water, surface of natural lacquer polished to a mirror-gloss deep crimson / black, hollow inside with light catching at the thin edge, visible layered fiber-thin wall texture, still-life studio side light showing warm lacquer sheen, --s 130 --style raw --ar 1:1
    ```

    参数说明：`--s 130`（中档——辨识在「超薄壁+镜面大漆+去胎内空」三重物理约束上，中档让材质读出来又不被加戏）；`--style raw`；`--ar 1:1` 器形。
