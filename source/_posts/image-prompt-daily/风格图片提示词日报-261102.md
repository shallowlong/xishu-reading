### 1. Burl 瘿木鸡冠纹 / Cock's-comb & Fiddlehead Figure
- **来源**：BeaverCraft Tools《Burl Wood》术语词条 https://beavercrafttools.com/blogs/glossary/burl-wood + Global Wood Source《How to Properly Cut and Preserve Burl Wood》https://www.globalwoodsource.com/blog/how-to-properly-cut-and-preserve-burl-wood/
- **标签**：微距 / 分形
- **一句话特征**：看着是一块"木头"，其实是菌瘤/虫蛀逼出来的**紊乱生长**——满屏密集的漩涡"眼"状节疤（eyes）+ 蕨叶纹（fiddlehead）+ 鸡冠纹（cock's comb），纹理不再顺着一个方向走，而是几百个微型漩涡互相缠绕，抛光上油后每一圈眼都有玻璃般的高光反射。
- **为什么有意思**：这是**物理材质模拟 + 分形自相似**的罕见双料命中。普通木材的纹理是"顺直平行"的先验（AI 也这么画），而瘿木（burl）是树在感染真菌或被虫蛀时局部生长激素紊乱、维管束被逼成螺旋结疤——**纹理本身就是"病态"长出来的**。它冷门在：绝大多数人会画"直纹松木/橡木"，几乎没人会画"满屏漩涡眼"。技法来源可追溯到**木皮薄切（veneer）**——木匠把瘿木瘤切成 0.5–1mm 薄片贴到桌面、盒子、乐器面板上，"薄薄一层裹住整块瘤的乱纹"，这是真正的**复古工艺**（巴洛克时期欧洲盒子与小提琴面板首选料）。与已收录 10-15 Mokume-gane（金属层压假装木纹）**方向正好相反**：本条是**真木头假装成"乱纹艺术"**，靠天然结疤非金属锻打。
- **通用提示词**：
```
extreme macro photograph of a polished burl wood surface, dense swirling fiddlehead and "cock's comb" grain with many tight eye knots and irregular whorls, warm amber and umber tones, thin oil finish with soft specular highlights, raking side light, ultra detailed natural wood texture
```
- **效果图参考**（agnes-image-2.5-flash，2K / 1:1）：![Burl 瘿木鸡冠纹](https://pic1.imgdb.cn/i/034tsHG7OPX6ySSI5Q5knb.webp)
- **分工具适配**：
  - **Midjourney**：
    ```
    extreme macro photograph of polished burl wood surface, dense swirling fiddlehead and cock's comb grain with many tight eye knots, warm amber umber, thin oil finish with specular highlights, raking side light --style raw --s 150 --ar 1:1
    ```
    参数说明：`--style raw` 拉满写实防被加滤镜；`--s 150` 密度中高档（防被抹回直纹松木）；微距器物用 `--ar 1:1`。
  - **即梦**（中文，名词顿号无逗号）：
    ```
    瘿木抛光木皮微距，满屏漩涡蕨叶纹鸡冠纹，密密麻麻眼状节疤，暖琥珀色厚木油，侧光掠射高光，超精细天然木质纹理
    ```
    （`sample_strength` 建议 0.5–0.7，待验证；过低→退成普通木纹，过高→眼纹糊成一团。）
  - **可灵 Kolors**（中文 + `guidance_scale` 区间）：
    ```
    微距：一块抛光的瘿木（瘤木）木皮，表面布满密集的蕨叶纹、鸡冠纹与漩涡状"眼"节疤，纹理紊乱不规整，暖琥珀与深赭色，薄木油涂层有镜面高光，斜侧光，超高细节
    ```
    `guidance_scale` 建议 5–8（偏低会退直纹，偏高漩涡会崩）。
  - **通义万相**（本条按 V2 写，附 negative_prompt）：
    ```
    正向：瘿木瘤木抛光木皮微距，满屏蕨叶纹鸡冠纹漩涡眼节疤，暖琥珀厚木油，侧光镜面高光，超精细
    负向：straight straight grain, pine wood, oak wood, smooth plain wood, blurry, lowres, cartoon, illustration
    ```
  - **Seedream（火山方舟）**（2K 档 + 英文专名词源）：
    ```
    burl wood, cock's comb figure, fiddlehead grain, extreme macro, polished veneer, oil finish, amber umber
    ```
  - **Stable Diffusion**（SDXL / SD3.5）：
    - 正向：`burl wood veneer, extreme close-up macro, swirling fiddlehead and cock's comb grain, dense eye knots, whorls, polished thin oil finish, specular highlights, raking light, amber and umber tones, photorealistic, 8k detail`
    - 负向：`straight grain, pine, oak, smooth wood, cartoon, illustration, lowres, blurry, jpeg artifacts, logo, text, watermark`
    - LoRA 建议：纯正向写死即可；可选借 `wood texture` / `macro photography` 近亲件权重 0.2–0.3，**必须加负向 `straight grain` / `oak` / `pine`** 把先验直纹压住，不编造专属瘿木文件名。
- **避坑**：AI 默认先验是"顺直纹理木材"（与 10-10-12 记账一致——模型对直纹的先验压倒性），不写满 `swirling / fiddlehead / eye knots / irregular whorls` 会被默默画成松木桌面。其次是**漩涡密度**：`--s` 或 `guidance` 给低就只剩几根弧线，给高就糊成麻花——中高档最合适。油光高光要用"斜侧光 raking light"喂，正面打光会把"眼"的立体感抹平。
- **可选 · 服装/童装用法**：瘿木的"满屏不规则漩涡眼纹"天然就是一张**满铺纹理印花底**——做童装外套、家居服的面料提花/数码印花时，可取这张的漩涡密度做平铺底纹，比常规直条纹提花更有"高级感"辨识点（一眼认出"这不是普通条纹"）。

### 2. Shakudō 朱铜 / Rokushō Patina
- **来源**：日本政府官方《The Production and Use of Gold in Japan》https://www.gov-online.go.jp/eng/publicity/book/hlj/html/202210/202210_01_en.html + Wikipedia《Shakudō》https://ergngevd.top/wiki/Shakud%C5%8D + HandWiki《Rokushō》https://handwiki.org/wiki/Engineering:Rokush%C5%8D
- **标签**：微距 / 高对比
- **一句话特征**：看着是一块"黑铁/铜"，其实是**铜+金（约 3%）+锡/锑**的合金经 `niiro` 着色——把金属浸进沸腾的 `rokushō`（绿青，醋酸铜/硫酸铜/醋液混合液），**金属表面会慢慢"渗"出深紫近黑的血色（blood color）**，掠光角度下浮起一层虹彩的紫蓝青光泽，而正面看就是一片死黑。
- **为什么有意思**：这是**复古媒介复活 + 物理材质（合金成膜）**的冷门命中。日本独有的 shakudō 合金，名字拆开"shaku=赤、dō=銅"，却偏偏染成黑紫色——**名字说"红铜"、成品是"黑紫"，反直觉**。它的紫不是颜料涂上去的，是**金属本身在热水醋液里慢速化学成膜**（`rokushō` 配方：约 6g 醋酸铜 + 硫酸铜 + 醋/水，沸腾中不断搅动，紫得越多金含量越高）——**颜色是"泡"出来的，不是"画"出来的**，跟 10-28 钧瓷"入窑一色出窑万彩"是同一个母题（色来自烧/泡，非笔）。它冷门在：西方金属学里有"Corinthian bronze / Hepatizon"近亲，但几乎没人知道 shakudō 的紫黑虹彩是**合金+慢速化学双色叠加**的结果，AI 画"深色金属"极易画成一块死黑铁或黄铜，认不出那个掠光紫蓝虹彩。技法来源可追溯到**江户·明治时代刀剑装具（tsuba 刀镡、menuki 镡绳）与 mokume-gane 锻打金属**——现在被西方高级珠宝复活。
- **通用提示词**：
```
macro photograph of a shakudo copper-gold alloy surface, glossy near-black deep purple patina with a subtle iridescent violet-blue sheen shifting in the light, dark metallic bronze-black tone, fine polished tool marks, raking light, high detail
```
- **效果图参考**（agnes-image-2.5-flash，2K / 1:1）：![Shakudō 朱铜](https://pic1.imgdb.cn/i/034tsGL1P7cjz316zn0Vnv.webp)
- **分工具适配**：
  - **Midjourney**：
    ```
    macro photograph of shakudo copper-gold alloy surface, glossy near-black deep purple patina, subtle iridescent violet-blue sheen shifting in light, fine polished tool marks, raking light --style raw --s 130 --ar 1:1
    ```
    参数说明：`--s 130` 中档（虹彩金属密度中档，防被抹成普通黑铁/黄铜）；掠光角度是关键，务必写 `raking light` 才能浮出紫蓝虹彩。
  - **即梦**（中文）：
    ```
    朱铜金属微距，深紫近黑金属光泽，掠光下浮紫蓝虹彩，细腻抛光刀纹，暗部死黑，传统日本金属，超精细
    ```
    （`sample_strength` 建议 0.5–0.7，待验证。）
  - **可灵 Kolors**（中文 + `guidance_scale`）：
    ```
    微距：一块 shakudo 朱铜合金表面，深紫近黑的金属光泽，斜掠光下浮出虹彩紫蓝青光泽，金属底色为青铜黑，表面有细腻抛光刀痕，暗部死黑，超高细节
    ```
    `guidance_scale` 建议 5–8。
  - **通义万相**（V2 + negative_prompt）：
    ```
    正向：朱铜金属微距，深紫近黑，掠光虹彩紫蓝，抛光刀痕，暗部死黑，超精细
    负向：brass, yellow copper, wood, stone, plastic, cartoon, flat color, blurry, lowres, logo, text
    ```
  - **Seedream（火山方舟）**（2K 档 + 英文专名词源）：
    ```
    shakudo alloy, copper patina, deep purple-black iridescent, raking light, macro
    ```
  - **Stable Diffusion**：
    - 正向：`shakudo metal, macro close-up, deep purple-black patina, iridescent violet-blue sheen, glossy copper-gold alloy, fine tool marks, raking light, dark background, photorealistic, 8k`
    - 负向：`brass, yellow copper, wood, stone, plastic, flat color, cartoon, illustration, lowres, blurry, jpeg artifacts, text, logo`
    - LoRA 建议：纯正向写死；可选借 `metal macro` / `jewelry` 近亲件 0.2–0.3，**必加负向 `brass` / `wood` / `stone` / `plastic`** 压住材质先验，不编造专属文件名。
- **避坑**：最大的坑是**掠光**。shakudo 的紫蓝虹彩只在斜侧光掠射时才浮出，正面平光打下来就是一块死黑——**prompt 里必须写死 `raking light / low side light`**。其次是材质认不出：AI 容易画成"一块黑铁""一块塑料"或"黄铜"，要反复强调 `copper-gold alloy / iridescent / metallic sheen`。最后**颜色别溢出**——掠光紫蓝一给过头会跑成"紫色金属玩具"，虹彩要"subtle"。
- **可选 · 服装/童装用法**：省略（合金掠光虹彩硬套到童装面料缺乏自然联想，不写）。

### 3. Petrified wood 硅化木 / 树化玉（Tree Quartz）
- **来源**：ScienceDirect《Silica phase-transformations during diagenesis within petrified woods》(Sedimentary Geology) https://www.sciencedirect.com/science/article/abs/pii/S0037073813000560 + 科普中国《木石奇缘——硅化木》https://www.kepuchina.cn/article/articleinfo?ar_id=748308&business_type=100 + 中国自然资源报《远古的"森林"去了哪里》https://www.iziran.net/news.html?aid=5406396
- **标签**：玻璃 / 微距
- **一句话特征**：看着是"木头年轮"，其实是**二氧化硅逐分子置换木质纤维**石化成的石头——横截面上一圈年轮、一根根管壁细胞纹都清清楚楚，但材质是**坚硬半透明的石英/玉髓**（硬度 6.5–7），铁锰致色离子把石头染成琥珀、红褐、灰黑，玻璃光泽，**"木形而石质"**。
- **为什么有意思**：这是**物理材质模拟 + 地域文化（中国化石森林）**的顶级命中，母题是"**看着是 A（木），其实是 B（石）**"。科学上极精妙：硅化木的矿物学叫"交代作用（replacement / permineralization）"——含硅地下水**一边溶解木质纤维、一边把二氧化硅沉回空腔**，最终碳元素荡然无存、全换成硅，**年轮和细胞却原封不动留了下来**。它冷门在：绝大多数 AI 画"树桩横截面"会画成**活的木头**（有木纹、有年轮、有木色），**画不出"年轮是石头的"那一层反直觉**。它还有个中国在地感——**新疆古生态园有全球最大硅化木森林**（最长 56 米，超美国黄石吉尼斯记录的 37 米），"树化玉"（硅化木中二氧化硅变质成玉髓的种）是收藏界高价值件。技法来源可追溯到**矿物学/古生物学化石工艺 + 玉雕行当的"树化玉"切割**。与 10-15 Mokume-gane **方向完全相反**：Mokume 是**金属假装木头**（人做），本条是**石头假装木头**（天做）；与 10-14 漆线雕/堆绣（织物塑料厚度）也互不撞。
- **通用提示词**：
```
close-up macro photograph of a polished petrified wood tree quartz cross section, clearly preserved annual growth rings and cellular wood grain rendered in hard translucent silica stone, warm amber, red-brown and grey iron-oxide mineral colors, glossy glassy stone surface that still reads as wood, studio light, ultra detailed
```
- **效果图参考**（agnes-image-2.5-flash，2K / 1:1）：![Petrified wood 硅化木](https://pic1.imgdb.cn/i/034tsIgmODhYBoVfpiWEmq.webp)
- **分工具适配**：
  - **Midjourney**：
    ```
    close-up macro of a polished petrified wood tree quartz cross section, clear annual growth rings and cellular grain in hard translucent silica stone, amber red-brown grey iron-oxide mineral colors, glossy glassy surface that reads as wood, studio light --style raw --s 150 --ar 1:1
    ```
    参数说明：`--s 150` 密度中高档（年轮+矿物色要喂足，防退成普通木桩）；关键矛盾句 `that still reads as wood` 必须留，逼模型抓住"木形石质"的反直觉。
  - **即梦**（中文）：
    ```
    硅化木树化玉横截面微距，清楚年轮，木质细胞纹理，坚硬半透明石英石，琥珀红褐灰矿物色，玻璃光泽，看着像木头其实是石头，超精细
    ```
    （`sample_strength` 建议 0.5–0.7，待验证。）
  - **可灵 Kolors**（中文 + `guidance_scale`）：
    ```
    微距：一块抛光的硅化木（树化玉）横截面，能清楚看到树木年轮和木质细胞纹理，但材质是坚硬半透明的二氧化硅石英石，铁锰致色的琥珀、红褐、灰黑矿物色，玻璃光泽，影棚光，超高细节
    ```
    `guidance_scale` 建议 5–8。
  - **通义万相**（V2 + negative_prompt）：
    ```
    正向：硅化木树化玉横截面微距，清楚年轮木质细胞，半透明石英石，琥珀红褐灰矿物色，玻璃光泽，影棚光，超精细
    负向：soft wood, fresh timber, wood fiber, bark, cartoon, illustration, blurry, lowres, logo, text
    ```
  - **Seedream（火山方舟）**（2K 档 + 英文专名词源）：
    ```
    petrified wood, tree quartz cross section, annual rings, translucent silica stone, amber red-brown iron-oxide, glossy, macro
    ```
  - **Stable Diffusion**：
    - 正向：`petrified wood tree quartz, macro cross section, clear annual growth rings, cellular wood grain in translucent silica stone, amber red-brown grey iron-oxide mineral colors, glossy glassy stone surface, studio light, photorealistic, 8k`
    - 负向：`soft wood, fresh timber, wood fiber, bark, cartoon, illustration, lowres, blurry, jpeg artifacts, text, logo`
    - LoRA 建议：纯正向写死；可选借 `stone macro` / `geode` / `mineral texture` 近亲件 0.2–0.3，**必加负向 `soft wood` / `timber` / `wood fiber`** 压住"活木头"先验，不编造专属文件名。
- **避坑**：核心难点是**"年轮是石头"的矛盾感**——AI 先验会把它画成普通木桩（有木色、无玻璃感），必须用 `translucent silica stone / glassy surface / reads as wood` 三个词组反复锚定"木形石质"。其次是**矿物色别糊成一片棕**——要写出 `amber / red-brown / grey iron-oxide` 三色分布（对应铁/锰/钛致色离子），否则会出一坨脏棕。最后是**玻璃光泽**：石头的玻璃/玉髓反光要用 `glossy / studio light` 喂，哑光就丢"树化玉"的玉质感。
- **可选 · 服装/童装用法**：省略（硅化木矿物色硬套童装面料缺乏自然联想，不写）。
