今日母题：**「色彩不是调出来的，是被一层层叠/滤/感光"长"出来的」**——染料转移＝三层减色胶膜依次浸染叠印（颜色靠浸染非调墨）；透明罩染＝透明色滤下层不透明底、光来回穿两次弹回（辉光靠双程滤光非调色）；盐印＝阳光直晒氯化银让银自己沉积发黑（影像靠感光沉积非显影剂）。三条都讲"画面靠材料的物理层叠/滤光/沉积，不靠颜料一次性调和"。

### 1. Dye Transfer 染料转移彩色印相（Kodak DT / Technicolor 同源）
- **来源**：Graphics Atlas「Dye Imbibition / Dye Transfer」工艺档案页 + HNOC 早期工艺时间线 — http://www.graphicsatlas.org/identification?process_id=61 ｜ https://hnoc.org/virtual-exhibitions/from_daguerreotype_to_digital/gelatin-silver-developing-out-paper-process
- **标签**：胶片、暗房、高对比
- **一句话特征**：一张正像是三张不同颜色的胶膜**依次套印**叠出来的——先印青、再品红、最后黄，CMY 三网屏严丝合缝；色彩比当时 C-41 冲印更纯、暗部更深、色相边界更"硬"，放大后能感到颜色是"一层面层面罩上去"的厚重感，而不是喷墨那种像素渗。
- **为什么有意思**：冷门且被历史埋没的工艺。1880 年 Charles Cros 发现重铬酸明胶能"吸放染料"（dye imbibition 吸染原理），1920s Technicolor 拿它做电影胶片，1946 年柯达把它民用成 Dye Transfer，一直用到 **1993 年停产**——那十几年它是时尚摄影、广告大片、博物馆展陈的主力（比同时期 C-41 冲印更稳定、色彩更宽）。它的色彩 gamut 甚至宽于今天的喷墨。最大翻车点 = **套色误差 misregistration**：三层膜只要错开一丝，边缘就出现红绿青的"鬼影重影"，这是它最标志性的视觉签名。冷在"1993 年突然退场、如今只有极少数手工艺印刷者在复原"。
- **通用提示词**：
```
1970s fashion photography, dye transfer print process, three-color CMY imbibition,
deep saturated color gamut, rich layered color with subtle edge misregistration,
soft highlight bloom, heavy shadow density, archival color, slightly coarse halftone grain,
large-format fashion editorial aesthetic, mid-century color print look
```
- **效果图参考**（agnes-image-2.5-flash，2K / 1:1）：![Dye Transfer 染料转移彩色印相](https://pic1.imgdb.cn/i/034trBmRM6Ab6aveegXvoX.webp)
- **分工具适配**：
  - **Midjourney**（国际主流）：
    ```
    1970s fashion editorial, dye transfer print process, three-color CMY imbibition, rich layered color gamut, subtle edge misregistration, soft highlight bloom, heavy shadow density, archival mid-century color print --s 150 --style raw --ar 4:5
    ```
    参数说明：`--s 150`（中高档——套色厚重感+CMY 高饱和，但要防模型把"误对齐"演成全画面糊掉，故不到 200）；`--style raw`（防 MJ 自动打光打柔）；`--ar 4:5`（时装编辑竖幅）。misregistration 只写"subtle edge"限定在边缘，别写满屏。
  - **即梦 Jimeng**（国产）：
    ```
    1970年代时尚摄影，染料转移印相工艺，CMY三原色浸染套色，层叠厚重色彩，边缘轻微套色误差，高光柔化泛晕，暗部深密，档案级色彩，中等颗粒，中世纪胶片色彩美学
    ```
    按官方「艺术风格 + 主体描述」模板，名词顿号连接、句内不用逗号（逗号会被判成新指令）。`sample_strength` 标「待验证」。
  - **可灵 Kolors**（国产）：
    ```
    （提示词同即梦版；）guidance_scale 建议 4–7（低档——套色是"叠加"而非"生成"，指导太高压平色彩层次）
    ```
  - **通义万相**（国产）：本条按 **V2** 写，支持 `negative_prompt`：
    - 正向：`1970s 时尚大片，染料转移 CMY 套色印相，层叠厚重色彩，边缘轻微套色重影，暗部深、高光柔，档案级色域，中世纪胶片色调`
    - negative_prompt：`模糊套色、整面糊、塑料感、过饱和霓虹、现代数码锐利、文字`
  - **Seedream（火山方舟）**：按官方「主体 + 行为 + 环境 + 美学短语」，专业词用词源语言（`dye transfer`/`imbibition`），出 2K/4K。
    ```
    一张 1970 年代时装大片，染料转移 dye transfer 印相工艺，CMY 三原色减色叠印，色彩层叠厚重，边缘有 subtle misregistration 套色重影，高光 bloom，暗部深密，档案级色域，vintage color print
    ```
  - **Flux.1（BFL）**（国际）：
    ```
    A 1970s fashion editorial photograph printed via the Kodak dye transfer process, three-layer CMY imbibition, deeply saturated archival color, rich color layering with subtle edge misregistration, soft highlight bloom, heavy shadow density, mid-century color print aesthetic, large-format print
    ```
  - **Stable Diffusion（SDXL / SD3.5）**（国际）：
    - 正向：`1970s fashion editorial, dye transfer print, three-color CMY imbibition process, rich layered color gamut, subtle edge misregistration, soft highlight bloom, heavy shadow density, archival color, medium halftone grain, mid-century color print look`
    - 负向：`blur, smeared color, plastic skin, oversaturated neon, modern digital sharpness, banding, JPEG artifacts, text, watermark`
    - LoRA 建议：本条非周二，未做 Civitai 实测，纯靠正向写死；`dye transfer` 属冷门专名，近亲可借"复古胶片/老照片"类 LoRA 限权 **0.2–0.3**，不要拉高（会盖掉套色结构）。
- **避坑**：①"误对齐 misregistration"一定限定**边缘**（subtle edge / color fringing on edges），写满屏就成故障艺术翻车；②CMY 三网屏套色容易被模型理解成"分色印刷网点"，要写"层叠厚重"而非"halftone dots"；③暗部"深密"别写成"死黑死灰"，DT 暗部是有颜色的；④别加 `--no misregistration` 之类，重影是它的灵魂。
- **可选 · 服装/童装用法**：童装彩色面料打样、印花样布想体现"面料色彩比数码渲更深更厚"时，用这条 CMY 套色厚重感 + 边缘轻微重影，能拍出"手工印染实物感"。

### 2. Glazing 透明罩染（古典油画间接画法 · 光学灰）
- **来源**：Britannica「The Head of Medusa / oil painting layers」+ Essential Vermeer「Glazing」技法专页 + 百度百科「透明画法」— https://www.britannica.com/topic/The-Head-of-Medusa ｜ https://www.essentialvermeer.com/technique/technique_glazing.html ｜ https://baike.baidu.com/item/透明画法/893954
- **标签**：油画、柔焦、高对比
- **一句话特征**：画面没有一块"调好的死色"——深色是**透明色一层层罩**在浅色底上，光透进色层、被下层弹回、再穿两次才到眼睛，所以整幅画有从里面透出来的"辉光"，暗部不灰不脏、像玻璃后面有灯。
- **为什么有意思**：这是 19 世纪前欧洲画派的**核心秘密**，被直接画法（alla prima）取代后几近失传。关键概念是「**光学灰**」——把透明蓝罩在透明红上、或透明黄底下接冷色，叠出的灰是"活"的、带内在辉光的，跟颜料盘上物理调出的死灰完全不同（百度百科原话"珠宝般的光泽"）。技法线：15 世纪凡·艾克把油媒介透明度推到极致 → 文艺复兴达·芬奇用上百层超薄罩染做出**晕影 sfumato** → 提香把"受光部厚涂、暗部透明罩染"玩成戏剧 → 伦勃兰用暗部罩染做**明暗对照 tenebrism**。冷在"现在几乎没人还这么画，但你看老油画的那种'里面在发光'，就是它"。
- **通用提示词**：
```
classical old master oil painting, indirect glazing technique, dozens of transparent glaze layers,
luminous internal glow, optical gray (optical grays built by layering transparent colors),
deep rich shadows with internal light, jewel-like color depth, Van Eyck / Rembrandt style,
subtle sfumato transitions, matte egg-tempera ground under transparent oil glazes
```
- **效果图参考**（agnes-image-2.5-flash，2K / 1:1）：![Glazing 透明罩染](https://pic1.imgdb.cn/i/034trAudaTv1r5WMPml1ly.webp)
- **分工具适配**：
  - **Midjourney**（国际主流）：
    ```
    classical old master oil portrait, indirect glazing technique, dozens of transparent glaze layers, luminous internal glow, optical gray shadows with inner light, jewel-like color depth, Rembrandt tenebrism, sfumato transitions --s 120 --style raw --ar 3:4
    ```
    参数说明：`--s 120`（中档——辉光是"透"出来的不是"堆"出来的，中档刚好出玻璃质感，太高会堆出厚涂）；`--style raw`；`--ar 3:4`（肖像）。
  - **即梦 Jimeng**（国产）：
    ```
    古典老大师油画肖像，透明罩染间接画法，多层透明色罩叠染，内在辉光，光学灰暗部透出微光，宝石般色彩深度，伦勃朗明暗对照，晕影过渡，哑光蛋彩底层上罩透明油色
    ```
    顿号连接、无逗号。
  - **可灵 Kolors**（国产）：提示词同即梦版；guidance_scale 建议 **5–8**（中档——要保住"透明层"的细腻过渡，指导太高会压成单色厚涂）。
  - **通义万相**（国产）：本条按 **V2** 写：
    - 正向：`古典老大师油画，透明罩染间接画法，多层透明色罩染，暗部有内在辉光，光学灰，宝石般色彩深度，伦勃朗明暗对照，晕影`
    - negative_prompt：`平面单色、厚涂肌理、现代丙烯、数码锐利、高饱和霓虹、笔触外露`
  - **Seedream（火山方舟）**：`一幅古典老大师油画肖像，transparent glazing 透明罩染间接画法，多层层叠透明色滤，内在辉光，optical gray 光学灰暗部透出微光，jewel-like color depth 宝石般色深，伦勃朗 tenebrism 明暗对照，sfumato 晕影`，出 2K/4K。
  - **Flux.1（BFL）**（国际）：
    ```
    a classical old master oil portrait painted with the indirect glazing method, dozens of transparent glaze layers over an egg-tempera underpainting, luminous internal glow, optical gray shadows with inner light, jewel-like color depth in the darks, Rembrandt-style tenebrism, sfumato transitions, matte surface
    ```
  - **Stable Diffusion（SDXL / SD3.5）**（国际）：
    - 正向：`classical old master oil painting, indirect glazing technique, many transparent glaze layers, luminous internal glow, optical gray shadows with inner light, jewel-like color depth, Rembrandt tenebrism, sfumato, egg-tempera underpainting, matte`
    - 负向：`flat single color, thick impasto, modern acrylic, digital sharpness, high saturation neon, visible painterly brushstrokes, 3d render, cartoon`
    - LoRA 建议：非周二未实测；`glazing`/`old master oil` 近亲可借"古典油画/master painter"类 LoRA 限权 **0.3–0.4**，重点正向写死"多层透明罩染 + 光学灰"，防模型退化成单色厚涂。
- **避坑**：①"罩染"容易被模型画成"透明水彩/湿透"——要强调**油画透明层 + 底层哑光蛋彩**的厚薄对照，不是纸上的水彩；②"辉光"别写成"霓虹发光/glow"，是"玻璃后面有灯"的内透；③光学灰是**透明色叠出的活灰**，别写成"低饱和灰调"（那是死灰）；④人物皮肤要"罩染出的通透"，不是"厚涂高光"。
- **可选 · 服装/童装用法**：拍薄纱、针织透光面料时，用这条"光透两层弹回"的内在辉光 + 光学灰阴影，能表现"纱线里透光、面料背后有光源"的通透质感。

### 3. Salt Print 盐印（塔尔博特氯化银盐纸 · 19 世纪中叶主流）
- **来源**：Wikipedia「Salt print」+ EBSCO「William Henry Fox Talbot」研究条目 — https://wikipedia.com/wiki/Salt_print ｜ https://ebsco.com/research-starters/visual-arts/william-henry-fox-talbot
- **标签**：胶片、暗房、褪色
- **一句话特征**：1839–1860 年**几乎所有早于银印相的照片都是这么印的**——用食盐 + 硝酸银涂出氯化银感光层、阳光直晒让银自己沉积发黑，成品是**暖棕（sepia）偏金、纸质纤维粗、高光发亮、暗部闷软**的一张照片，边缘常留一圈未曝光的白边。
- **为什么有意思**：这是**摄影史上第一个能"复制"正像的纸质印相工艺**（塔尔博特 1839 发明，"光画 photogenic drawing"），奠定了后来"负片→正片"整套可复制逻辑的起点——而它的主流地位只维持到 1860 年前后被银印相取代，如今只在艺术摄影里作为"替代工艺 alternative process"小众复活。冷在"几乎所有人拍过/看过盐印却没人知道它曾经是'照片'这个词本身的样子"。技术细节硬：印出过程（printing-out，非 developing-out）、相机要曝**一小时以上**才出影像、盐比银少的地方最感光（塔尔博特的反直觉发现）、可再上**金调（gold toning）**防褪。与已收录的 Tintype（铁版）、Autochrome（彩屏）不同体系。
- **通用提示词**：
```
1850s salt print photograph, Fox Talbot style, warm sepia-brown tones, visible paper fiber texture,
high-key highlights, soft matte shadows, unexposed white border edge, contact-printed calotype negative look,
early photography, aged silver chloride paper, hand-held subject of a 19th century scene
```
- **效果图参考**（agnes-image-2.5-flash，2K / 1:1）：![Salt Print 盐印](https://pic1.imgdb.cn/i/034trAzQVqy3P6Z04t5IYy.webp)
- **分工具适配**：
  - **Midjourney**（国际主流）：
    ```
    1850s salt print photograph, warm sepia-brown tones, visible coarse paper fiber, high-key highlights, soft matte shadows, unexposed white border, early 19th century photography look, Talbot style contact print --s 100 --style raw --ar 4:3
    ```
    参数说明：`--s 100`（低档——盐印的辨识度全在"暖棕 + 粗纤维 + 白边"这套极简约束上，stylize 一高就被模型加戏成现代老照片）；`--style raw`；`--ar 4:3`（19 世纪相框比例）。
  - **即梦 Jimeng**（国产）：
    ```
    1850年代盐印照片，塔尔博特风格，暖棕色调，可见粗纸纤维纹理，高光发亮，暗部哑光闷软，边缘留未曝光白边，早期摄影接触印相质感，氯化银盐纸做旧，19世纪场景
    ```
    顿号连接、无逗号。
  - **可灵 Kolors**（国产）：提示词同即梦版；guidance_scale 建议 **4–7**（低档——盐印靠"暖棕 + 纤维 + 白边"定形，指导太高压不出哑光闷调）。
  - **通义万相**（国产）：本条按 **V2** 写：
    - 正向：`1850 年代盐印照片，塔尔博特风格，暖棕 sepia 色调，粗纸纤维纹理，高光发亮、暗部哑光闷软，边缘留白边，早期摄影接触印相`
    - negative_prompt：`现代老照片褪色感、塑料泛白、彩色、数码锐利、过曝、文字水印`
  - **Seedream（火山方舟）**：`一张 1850 年代盐印 salt print 照片，塔尔博特 Fox Talbot 风格，暖棕 sepia 色调，可见 coarse paper fiber 粗纸纤维，高光发亮、暗部 matte 哑光闷软，边缘 unexposed white border 未曝光白边，early photography 早期摄影接触印相质感，氯化银银纸做旧`，出 2K/4K。
  - **Flux.1（BFL）**（国际）：
    ```
    an 1850s salt print photograph, Fox Talbot style, warm sepia-brown tones, visible coarse paper fiber texture, high-key highlights, soft matte shadows, unexposed white border around the image, contact-printed early photography look, aged silver chloride paper
    ```
  - **Stable Diffusion（SDXL / SD3.5）**（国际）：
    - 正向：`1850s salt print photograph, warm sepia-brown tones, visible coarse paper fiber, high-key highlights, soft matte shadows, unexposed white border, early 19th century photography, Talbot contact print, aged silver chloride paper`
    - 负向：`color photo, modern faded vintage, plastic white cast, digital sharpness, oversharpened, high resolution 8k, modern camera, text, watermark`
    - LoRA 建议：非周二未实测；`salt print` 属冷门专名，可借"老照片/vintage photo/sepia"类 LoRA 限权 **0.2–0.3**，重点正向写死"暖棕 + 粗纤维 + 未曝光白边"。
- **避坑**：①最容易翻车成"现代做旧老照片（泛白塑料感）"——必须写死**粗纸纤维 + 高光发亮 + 暗部闷软**，压掉"泛白塑料"；②别和 10 月已收录的 Tintype（铁版金属）、Autochrome（微粒彩屏）混，盐印是**纸质**；③"褪色"只体现在**暖棕**上，不要整体去饱和（那会变成黑白）；④白边是"未曝光留白"不是"撕边毛边"。
- **可选 · 服装/童装用法**：童装品牌想拍"19 世纪工坊手作感"的产品图或吊牌视觉，用这条暖棕盐印 + 粗纸纤维 + 留白边，比泛泛的"复古做旧"更有来历。
