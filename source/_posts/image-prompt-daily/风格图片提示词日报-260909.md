> 今日来源：国产工具官方渠道（即梦 / 通义万相 wan2.7 / 可灵 Kolors / 火山方舟 Seedream） / 人民日报·杭州市文旅局·新浪收藏等工艺实体档案

**今日母题：画和被画的东西之间，永远隔着一层。**

三条都出自中国，三条的手艺人都在"颜料"和"底子"之间塞了一层别的介质——**木板、羊毛毡、炭精粉**——然后那层介质自己变成了图案。

- 夹缬：隔着两块雕花木板。图案 = 木板夹住、染液永远进不去的地方。
- 拱花：隔着一层羊毛毡。图案 = 完全没上墨、只被锤子挤出来的地方。
- 擦笔水彩：隔着一层炭粉。颜料不再被纸纤维吸附，而是挂在颗粒上，肤色是从颗粒的色点里长出来的。

三条全是"负形成像"——**图案由缺席构成**，不是由笔触构成。这也正是它们最不好生成的地方：AI 天生只会往上加东西，不会"不画"。

### 1. 蓝夹缬 Jia Xie（夹染 / clamp-resist dyeing）

- **来源**：人民日报海外版《救活蓝夹缬》https://paper.people.com.cn/rmrbhwb/html/2013-04/02/content_1220597.htm / 人民日报客户端《"温州蓝夹缬"的前世今生故事》https://www.peopleapp.com/rmharticle/30035121015 / 中国纺织报《留住传统印染的记忆》https://www.ctn1986.com/index.php?c=content&a=show&id=16578 / CRI 华语环球《雕花夹布浸 蓝白相与间》https://chinese.cri.cn/2022/08/22/ARTIALi4MdDqHdehL4KkI840220822.shtml / 今日中国《中国民间蓝染》http://www.chinatoday.com.cn/china/2005/05012/p48n.htm / 社区验证：Civitai API（civitai.red）检索 `clamp resist` 返回的全是 CLAMP《魔卡少女樱》角色 LoRA，检索 `indigo dye` 无任何工艺件
- **标签**：织物 / 低饱和
- **一句话特征**：靛蓝底子上浮出成组**严格左右对称**的白色人物剪影，被长方框或六角形边框圈住；白不是"留白"，是"被夹住的"；蓝白交界处有染料渗进纤维的毛边和深浅不匀的靛蓝层次，整块布是被面尺度（实物常见 280×220cm，由四条缝成，共 16 个图案）。
- **为什么有意思**：

  **① 它和印刷术是反的。** CRI 的原文说得很直接——"染液无法渗透花纹突出部分，却能通过凹进的部分进行染色，**与印章、字模印刷刚好相反**"。凸版印刷是凸起处吃墨，夹缬是凸起处夹紧不吃染液。你看到的白人白花，是那块布**被两块硬木型版夹死了十几次**的结果。中国雕版印染与印刷的源头，是"不让它上色"。

  **② 工艺细节全是硬参数。** 型版用枫树、杨梅树、棠梨树或红柴，成对雕刻、纹样完全对称；型版四周钻孔，染液从孔里流进镂空处；棉布被夹紧捆好下缸，约 10 分钟取出氧化一次，反复多次。染料是板蓝根植株打的靛青（"终朝采蓝，不盈一掬"，出靛期在每年 11 月）。

  **③ 它曾经是彩色的，后来"变穷"了。** 唐代夹缬是彩色：红（红花/苏木）、蓝（靛青）、黄（槐花）、绿（蓝黄复合）四色，白居易写"成都新夹缬，梁汉碎胭脂"，唐玄宗拿它当国礼送遣唐使。元明棉花普及后棉布吸染料量远大于丝，红黄染料太贵，工艺为了省钱退化成单一靛蓝。**一个因成本而被迫砍掉色彩的手艺**——这本身就是个好故事。

  **④ 冷门度拉满。** 唐代实物只在大英博物馆和正仓院；"典籍里已经死去，生活中却依然活着"，最后只在温州瑞安、乐清、苍南几个作坊存下来，2011 年进第三批国家级非遗。纹样以永昆（草昆）戏文人物为主，这在其他蓝染织物里是没有的。

  **⑤ 社区零命中（今日实测）。** Civitai 上东南亚 batik 有四个现成件（SD1.5 `batik` id 256474、`batik-pattern` id 406472、`batik-kopri` id 465449、SDXL `Batik` id 2613485），而夹缬**一个都没有**。中文圈被玩烂的"扎染/蜡染"和它同属唐代"四缬"，但夹缬是唯一没被模型学会的那个。

- **通用提示词**：

```

figures, six bilaterally mirrored opera characters inside a hexagonal frame, rectangular border

clamped the cloth shut, feathery dye bleed along every blue-white boundary, uneven indigo

plant-dyed surface, no gloss, flat overhead scan of a full quilt cover panel
```

  1. **头号坑：所有"靛蓝 / indigo / 蓝染"关键词都会把画面拉向日本。** 模型语义库里 shibori（绞缬）、刺子、蓝染暖帘、牛仔布占压倒多数。正向必须显式写 `Chinese jiaxie clamp-resist`，负向必须排 `shibori, tie-dye, batik, japanese, ukiyo-e, denim`。
  2. **对称性会丢。** 夹缬型版是成对雕刻的，实物纹样严格左右对称、一框六人。模型默认给你画一个不对称的单人物。正向里必须写 `bilaterally symmetrical, six mirrored figures`。
  3. **人脸会糊。** 蓝夹缬人物的五官只是刻版上的几根细线，白脸本身是"没染到"。你越要求五官清晰，模型越会把白脸填成正常人脸、把风格毁掉。正确做法是让脸部保持"白底 + 极细刻线"，接受它模糊。
  4. **语义污染（今日实测，中文工具尤其明显）**：Civitai 搜 `clamp resist` 返回的全是 CLAMP《魔卡少女樱》——"clamp" 这个词在英文模型里 100% 被"CLAMP 漫画团体"吃掉。中文工具里写"夹紧"也会被理解成机械夹具/晾衣夹。**永远用专名"夹缬 / jiaxie / clamp-resist dyeing"**，不要描述动作。
  5. **别指望布料物理感。** 模型画的"棉布"常常是牛仔或麻布。加 `handwoven cotton weft visible, coarse, low thread count` 会好一点。

- **可选 · 服装/童装用法**：蓝夹缬本来就是棉布**被面**（浙南婚嫁必备，"百子被""龙凤被""状元被"），蓝白配色 + 团花对称构图，直接就是儿童家居服、抱被、睡袋的满印花型方向。但靛蓝的**摩擦色牢度是出了名的差**，真做婴幼儿产品必须走 A 类检测，AI 图只能当灵感板，别当卖点图（色差投诉已经在 Aerochrome 那条上栽过一次了）。

### 2. 饾版拱花 Douban & Gonghua（十竹斋木版水印 + 无色压凸）

- **来源**：杭州市文化广电旅游局《非遗文化解码之国家级非物质文化遗产"木版水印技艺"》https://wgly.hangzhou.gov.cn/art/2024/3/8/art_1229733878_58953964.html / 中国青年网书画频道《写在〈十竹斋笺谱〉复刻面世之际》https://shuhua.youth.cn/zxzx/201901/t20190115_11844217.htm / 社区验证：Civitai API（civitai.red）检索 `mokuhanga` **零命中**；`woodblock print` 4 条命中全部是浮世绘/广重方向（Eldritch Wood Block Print SDXL id 357387、Flux 版 id 776131、Utagawa Hiroshige id 2644855）；`blind emboss` 全部命中"Blind Girl / Blind Archer"角色 LoRA
- **标签**：版画 / 3D
- **一句话特征**：宣纸上是一幅极淡雅的彩色套印小品（博古器物、花卉虫鱼、行云流水），但在**极低角度的掠射光**下，纸面浮起一层完全没有颜色的凸起轮廓——瓶子的弧线、鸟的羽翼、水波的纹路，全是靠纸纤维被压进凹槽形成的浅浮雕。画面里有一半的图案，是"看不见颜色"的。
- **为什么有意思**：

  **① 拱花是印刷史上唯一一种"靠不上墨来成像"的技术。** 杭州市文旅局的描述：把雕成圆纹凹陷的**阴版**拱砑在宣纸上——先雕一块凹下去的版，把宣纸拉上去，覆一层薄羊毛毡，再用**木制拱花锤用力旋转挤砑**，纸纤维被挤进凹槽，取下来图案就以无色或白色的纹样**凸现在纸面上**。"工巧素雅"，一个字都没印上去，图案却在那儿。

  **② 饾版是"分色套印"的祖宗，而且名字来自点心。** 一色刻一块小木版，甚至一种颜色还要分成由浅到深的若干块，**几十块甚至上百块**小版逐色由浅入深套印。之所以叫"饾版"，是因为那些小木版堆在一起形似五色小饼"饾饤"（dòu dìng，古代的一种堆叠供果）。**用甜点的名字命名了印刷术。** 张秀民《中国印刷史》说它"最善于保持中国绘画的本色和精神"。

  **③ 冷门中的冷门。** 明末胡正言 1644 年刊《十竹斋笺谱》，四卷共 283 种，其中"无华""宝素"两类**纯用拱花、不加色彩**——也就是说，这两类笺谱在扫描件里看起来几乎是空白纸。这是整本日报至今最"反图像"的一条：**它的签名特征是"几乎看不见"**。

  **④ 它把印刷术从平面推到了三维。** 饾版（彩色套印）+ 拱花（立体压印）结合，是明代彩色套印的巅峰，被视为世界彩色印刷的开端。2007 年进江苏省级非遗，2014 年"木版水印技艺"进国家级非遗。20 世纪 30 年代鲁迅与郑振铎耗时七年重编《十竹斋笺谱》才把它捞回来。

  **⑤ 对 AI 来说这是一道硬题。** 扩散模型天生只会"往上加像素"，它不知道怎么表达"这里有图案但没有颜色"。所以这条的价值不在出图多好看，而在**逼你重新学怎么写提示词**——你必须靠侧光和阴影去"逼"出那层浮雕，而不是靠描述图案本身。

- **通用提示词**：

```
Shizhuzhai gonghua blind-embossed xuan paper, a monochrome relief with NO ink at all — the
flower petals, vase contours and water ripples exist purely as raised paper fibres pressed
into an intaglio wood block, lit by extreme raking light from the left so every embossed line
casts a long soft shadow, only a whisper of douban colour-block printing in pale mineral
pigments, unsized xuan paper, matte, fibrous, no varnish, no gloss, macro shot at a 5 degree
```

### 3. 月份牌擦笔水彩 Rubbed-Charcoal Watercolour（郑曼陀 → 杭稚英）

- **来源**：新浪收藏《月份牌：夸张艳俗之外的软波普艺术》https://collection.sina.com.cn/plfx/20140325/1759147214.shtml / 千龙网《年画唤醒年味儿 勾勒市井各业百态》https://culture.qianlong.com/2016/0205/348116_4.shtml / 搜狐《老月份牌里看美女 当时的时尚风向标》https://www.sohu.com/a/82828946_255783 / 上海观察《月份牌：秋波顾盼，流年魅影》PDF http://app.why.com.cn/epaper/shzk/images/2012-07/03/A15/14-15.pdf / 社区验证：Civitai API（civitai.red）检索 `vintage advertising poster` 命中 **Vintage Chinese Advertising and Propaganda Hypernetwork（id 5957，SD1.5，无触发词）**；`chinese calendar poster` 零命中
- **标签**：装饰艺术 / 柔焦
- **一句话特征**：极细腻的粉嫩肤色，比照片甜、比画真实——皮肤上有明显的凹凸体积感，但表面覆着一层水彩的透明滋润；炭灰底子从半透明的水彩下面透出来，形成微微偏冷的暗部；鲜艳的衣饰 + 柔化的背景 + 德国喷笔统一过的整体色调；画面四周有商品边框和广告字。
- **为什么有意思**：

  **① 技法来源具体到工具。** 郑曼陀的原创：**用不开锋的羊毫尖沾炭精粉，在纸上揉擦出阴影打底**（"就像当今的女士上妆前先打粉底"），再用水彩反复晕染。千龙网记的是"先用不开锋的羊毫尖沾碳精粉揉擦阴影，使主体形象呈现立体感，再用西洋水彩反复晕染，使美女肤色白里透红"。

  **② 一句原文就把这个风格的物理本质说透了。** 新浪收藏那篇写："**在无数微细的炭精粉颗粒之上，颜料不再是被纸张的纤维所吸附，而是附着于微细颗粒。因此，人物的面容是在无数颗粒的色点变化中呈现出来的。**"——这就是今天母题的第三条：**画面和纸之间隔着一层粉**。在那个照相昂贵稀有的年代，这是一次"手工照相术"的发明。

  **③ 材料清单本身就是风格说明书。** 挪威水彩纸、英国炭精粉、美国水彩颜料、德国喷笔。最后一道工序是用**喷笔**调整整个画面的色调和虚实关系（"为了以后照相制版和印刷时能有较好的效果"）。

  **④ 一个让眼睛跟着人跑的彩蛋。** 郑曼陀在印刷完成的月份牌上**用生漆点画美女丹凤眼的黑眼珠**——生漆的折射率让眼珠在不同角度看过去位置会变，产生"眼睛会跟人跑"的效果。民国舆论夸他画的美人"肤质细如凝脂，行如弱柳扶风"。

  **⑤ 杭稚英的二次改造，是标准的"反直觉混搭"。** 他嫌郑曼陀"黑气"过重（炭粉擦重了容易脏），于是**减弱炭精粉、只擦明暗交界线** → 亮部艳丽、暗部通透；然后**借鉴迪士尼动画的鲜艳配色和电影镜头感**（他 1930 年代在上海电影院看《唐老鸭》《大力水手》）；人物比例拉长到 8–9 个头高。**中国仕女画设色 + 西洋水彩 + 美国卡通 + 上海 Art Deco** 四层叠在一起。评论者给它起了个名字叫"软普"（soft camp）——比西方的 camp 更软、更日常、更不硬。

  **⑥ 它其实是被低估的现代主义。** 有评论指出：上海的现代性外壳是外滩 Art Deco 建筑群，内核却是**能带进卧室的月份牌**。它是现代中国最早的广告形式，杭稚英被称为"中国现代广告之父"。而当年一位纯艺术画家曾当众呛他"你也配谈色彩"——今天没人记得那位画家画了什么。

  1. **头号坑：一写"细腻肤色"就变塑料磨皮。** 这是擦笔水彩最核心的辨识点，也是最容易丢的。必须在正向写 `visible charcoal powder grain under translucent wash`、`matte, not airbrushed`，负向写死 `plastic skin, airbrushed, smooth gradient skin, glossy`。
  2. **掉进"老上海旗袍美女"刻板印象。** 只写"旗袍美女"，模型给你的是现代写真 + 滤镜。加**具体道具**才能把年代感钉死：自行车、高尔夫球、电话、唱片、电炉、摩托车。杭稚英本人从没打过高尔夫，所以他画的球场旁边还有亭台楼阁——**这种"不合逻辑的混搭"才是月份牌的精髓**，可以故意写进去。
  3. **颜色溢出。** 杭稚英的特点是"鲜艳但不刺眼"，与纯迪士尼的区别在于暗部通透、有炭灰打底。用 MJ 时别拉 `--s` 到 750+；用通义万相时用 `color_palette` 把高饱和色控制在 20–25% 以内。
  4. **中文广告字**：MJ / SD 系必糊。要字就用可灵 Kolors 或 Seedream（双引号包住文字）。
  5. **别写成一般"老照片/复古海报"。** 区别就在那层炭粉：普通复古海报是平涂 + 做旧，月份牌是有真实体积感的半透明罩染。如果你的图看起来像褪色的照片，说明炭粉层没做出来。

- **可选 · 服装/童装用法**：月份牌就是**服装广告画的祖师爷**——人物 + 商品 + 边框日历的版式，今天童装的详情页头图、活动海报仍在用同一个骨架。可以借它的构图和配色逻辑。但**别直接照搬旗袍摩登女郎去卖童装**：一是儿童成人化的红线，二是审美过时。改成"民国童装广告画"更安全也更有趣。
