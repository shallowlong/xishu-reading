### 1. 汝窑天青釉 / Ru Ware Celadon（"雨过天青云破处"）

- **来源**：故宫博物院《汝窑天青釉圆洗》藏品页 https://dpm.org.cn/collection/ceramic/227122.html + 河南省文旅厅《宝丰汝窑博物馆：汝窑天青 雅冠天下》 https://hct.henan.gov.cn/2022/10-24/2628196.html + 百度百科《宋汝窑天青釉圆洗》（故宫研究员蔡毅撰稿） https://baike.baidu.com/item/宋汝窑天青釉圆洗/868392
- **标签**：陶瓷 / 低饱和 / 微距
- **一句话特征**：一整片像雨后天空一样匀净的淡青色（天青 / 粉青 / 卵青），釉面薄得像一层冻住的水在器表轻轻颤着；细密的蟹爪纹开片从口沿一路爬到圈足；器底露出的胎是**香灰色**（不是白），上面钉着三粒芝麻大的支烧痕，底心还刻着一个"乙"字。
- **为什么有意思**：
  - **反直觉点一：汝窑不是"青花"，它是"一块玉"。** 全器无纹饰、无画工、无人纹，通体只有釉色在变（天青 / 粉青 / 天蓝 / 卵青 / 月白），宋代人管这叫"雨过天青云破处"（柴肩《题御画》），一整套瓷就是一只被冻结的雨后天空。这种"靠单一釉色定生死"的做法在宋代五大名窑里独一份。
  - **反直觉点二：满釉裹足 + 芝麻钉，是为了不让胎露出来。** 汝窑烧的是**满釉器**（全身挂釉，只在底部留三到五枚细小的尖状支钉把器物架空垫烧）。烧完把支具敲掉，器底留下三粒芝麻粒大小的**露胎钉痕**，断面是白的——这是真汝窑的三大硬证据之一（另两个是"香灰胎"和"蟹爪纹"）。也就是说：**这件东西最珍贵的几个特征，全是工艺事故留下的疤**（釉在冷却时与胎收缩不同步 → 开片；垫烧怕粘 → 裹足支钉）。
  - **反直觉点三："玛瑙入釉"其实是个传说级的误解。** 文献记载汝窑用玛瑙作釉的原料，听着像"拿宝石做釉"，但现代检测说：玛瑙的主要成分就是二氧化硅，釉的主要成分也是二氧化硅，**加不加对釉的性质几乎没影响**——它只说明烧造宫廷用瓷"不惜工本"。这句来自故宫官网原文，是个教科书级的反直觉。
  - **技法来源**：宋代五大名窑之一（汝 / 官 / 哥 / 钧 / 定），"汝窑为魁"（宋人叶寘《坦斋笔衡》："本朝以定州白瓷器有芒不堪用，遂命汝州造青窑器……汝州为魁"）。北宋为宫廷烧造仅约 20 年（1086–1106），窑址在今河南宝丰清凉寺（"七五"期间全国十大考古发现），1987 年才被发现。传世品不足百件，"近尤难得"是南宋人的原话。釉中气泡"大而稀疏、寥若晨星"，胎与釉结合处迎光偶尔能看到极淡的粉红釉线。
  - **与库内近义项显式错开**：与 10-28 钧瓷窑变（铜系红紫在釉体内渗化流动）、10-27 曜变天目（黑釉上人工沉积银彩点斑造虹彩）、10-29 备前烧（无釉靠窑焰落灰出痕）、10-04 Lusterware 釉光陶瓷（过釉后二次低温还原烧出 <1μm 金属膜）—— 那些都是"颜色在釉里动 / 在釉面上加料"，**汝窑是铁系青釉本身在高温还原气氛里烧成均匀的一层天青，开片是釉胎收缩差，器底还有支烧钉**。与 09-06 Crystalline Glaze 结晶釉（釉内析出锌硅酸盐晶体长出花）也不同：汝窑釉里干干净净，**没有晶体**，只有气泡。

- **可选 · 服装/童装用法**：汝窑天青是极低饱和的粉调青，配童装最舒服的是"天青 × 月白 × 淡赭"的低饱和三色，配色上可以直接取它"单色定调 + 极简"的思路做整件；釉面那种半乳浊、哑光、不反光的手感，落到面料上就是**雾面涂层 / 仿瓷釉的柔软不反光面料**，比亮面漆面更接近真汝窑。

### 2. 泥染布 / Bògòlanfini（马里泥布 · "用泥画出来的布"）

- **来源**：The Met《Bògòlanfini (mineral-dyed cloth)》藏品页 https://metmuseum.org/art/collection/search/642873 + Cooper Hewitt《Bogolanfini Woman's Wrapper (Mali)》藏品档案 https://collection.cooperhewitt.org/objects/18687429 + Brown 大学「Off the Roll」全球纺织项目《Wrapper (Bogolanfini)》 https://engagingtheamericas.digitalscholarship.brown.edu/off-the-roll-highlights-of-a-global-textiles-project/wrapper-bogolanfini.1
- **标签**：织物 / 地域文化 / 高对比
- **一句话特征**：黑得发闷的底子上留着一层米白到灰白的**几何与具象图案**——蛇形折线、十字圆盘、人形、鸟形、鳄鱼，还有一圈密排的小豆点边饰；黑不是印上去的，是**用泥"盖"上去**的，所以黑与白的交界带着一圈毛毛的锈褐色晕，线也不完全直。
- **为什么有意思**：
  - **反直觉点一：这块布的名字里那个"泥"，不是染料，是"盖色"的工具。** bɔgòlanfini 三段拆开是 bɔgò（泥/土）+ lan（用/靠）+ fini（布）。整个流程是"减法"而不是"加法"：**先用 n'gallama 树叶（Anogeissus leiocarpa）煮出的单宁把整块白棉布染成亮黄并媒染**（这一步在成品里看不见，但它决定了泥能不能咬住布），晒干后用金属刮刀 / 木棍**把图案的轮廓先描出来**，再拿整个背景糊满泥。泥里是**高铁滑土**，它跟布上的单宁发生反应后颜色就"咬"进纤维里——**泥洗掉了，黑色留下了**。最后用皂 / 漂白剂把没上泥的地方的黄褪掉，图案才浮现成白。所以：**白是"原本的布"，黑是"泥盖出来的"。**跟所有"白是防染出来的"工艺正好相反——这里是黑是染出来的、白是留出来的。
  - **反直觉点二：成品上有三种完全不同的白，是三种不同的化学。** ① 留白（没上泥又被漂过的米白）；② 泥的**浮色晕**——泥水顺着棉纤维毛细渗出边界线外一圈锈褐色；③ 反复上泥两三次后呈现的**深棕**过渡带（Cooper Hewitt 藏品页明写 "The meticulous application of mud is repeated at least twice to achieve a rich, dark color"）。这种"边界不干净"恰恰是手工艺的签名。
  - **反直觉点三：泥要**在陶罐里发酵整整一年**，而且是潜水去河底捞的。** 尼日尔河底的高铁泥一年只采一次，采集是体力活（要潜水下河），挖回来装进陶罐密封发酵一年才可使用。整个流程 2–3 周，加上发酵就是一年起步。真正的"泥"其实是一个**被驯化了一年的化学试剂**。
  - **技法来源**：马里 Bamana 族的 Beledougou 地区（最高品质产地是 San 镇），**男人织布，女人染色**——一条窄织机上织出约 15cm 宽的棉条，再一条条缝成约 1m × 1.5m 的整幅。图案是**语言**：鳄鱼（班巴拉神话）、人形、十字（毛里塔尼亚贵妇的坐垫＝贵族象征）、圆盘（griot 鼓）都在讲具体的历史事件和谚语；女性从母亲那里学，一学就是多年。传统用途：猎人穿（当伪装衣，也当护符），成年礼 / 婚后 / 产后裹身。1970 年后由 Chris Seydou 等设计师带入国际时装，1991 年政治变革后生产从女性手里转到男性手里，一年的学徒制被短期培训取代，如今大批量版本改用**模板漏印**、生产快 6–7 倍——**这是"工艺被工业化吞掉"最干净的一个样本**（Met 与 Brown 的馆藏文献都点出了这一段）。
  - **与库内近义项显式错开**：库里有 10-29 **Adire 约鲁巴靛蓝防染**（同样是西非、同样是靛蓝系），但机制完全相反——Adire 是**挡住靛液**（针缝 / 淀粉膏 / 扎结）让白留在布上，且染料是靛蓝（还原 → 氧化显蓝）；泥染布是**用泥把黑盖上去**，染料是高铁黏土 + 单宁媒染，颜色是铁的黑色不是植物的蓝。而且 Adire 的白是"防出来的"，泥染布的白是"漂出来的"。另有 10-13 Batik（蜡阻染）、10-12 Shibori（物理张力防皱）、10-02 枫香染（树脂牛油画出来的白）——**本条是"泥直接覆盖 + 事后褪色"，不靠任何防染介质**。

### 3. 18 世纪手绘上色铜版地图 / Hand-Coloured Copperplate Atlas Map（"每张都不一样的地图"）

- **来源**：Library of Congress《Neu und verbesserter Plan der St. u. Hafens Havana…》（Homann Erben / Thomas Bowles，1740，藏品标注 "2 maps on 1 sheet : hand colored"） https://www.loc.gov/item/74690542/ + ARGO（American Revolutionary Geographies Online）《Map of that part of Orange County lying to the north of the mountains》（1770s，手工笔+水彩 "Manuscript, pen-and-ink and watercolor"） https://www.argomaps.org/maps/commonwealth:q524nj62d/ + 牛津 Bodleian / ARGO 佛蒙特州 Cabot 镇地籍图（1780–89，"Manuscript, pen-and-ink. Cadastral map. hand color"） https://geo.leventhalmap.org/maps/5170
- **标签**：版画 / 蚀刻 / 褪色
- **一句话特征**：一张泛黄的老纸上，铜版雕刻的细黑线勾出山脉（成百上千道平行排线）、河流、城镇平面与树丛，然后**用淡水彩一版一版手工填色**——粉红、淡绿、赭黄、淡蓝各占一块，每块的颜色都**略微越过了雕刻的边界线**、在边缘积成一道深色圈，雕版线透过薄色依然清晰；四周有卷草纹的巴洛克图饰（cartouche）、指北玫瑰、比例尺。
- **为什么有意思**：
  - **反直觉点一：18 世纪的"印刷地图"其实每一张都是手工作品。** 铜版先印出**纯黑白**的线稿（铜版雕刻 = 线条凸起、滚油墨压纸），然后**出版商雇一批女画工（colourists）逐张手工上色**。所以**同一块铜版在世上存在几百个"版本"，每张的颜色组合都不相同**——同一张地图，A 版是粉+黄，B 版是绿+蓝，谁都挑不出"正版"。这在收藏市场里反而成了卖点："original hand colouring"（原版手工上色）是古地图行情的核心词，品相差别极大。
  - **反直觉点二：颜色的错位不是失误，是手工上色的必然。** 画工用毛笔蘸淡色，一块块填色，**很难不越过那条墨线**。所以每块色区的边缘都有一道"越界 + 积色"的深边（这是手工上色的最强辨识特征，也是判断真伪老地图的硬指标）。同时因为是**逐块薄涂**，雕版的排线会**透过来**——山脉的排线在粉红色块里清晰可见，这不是印刷瑕疵，是"先印线后手填色"的证据链。本期生成图里这一层关系完整成立。
  - **反直觉点三：这门手艺的技艺全在"排线"里，而排线不是画出来的，是刻出来的。** 山脉的立体感靠成百上千道**平行等距的细排线**（晕滃法 hachure）堆出来，城镇是网格状排线勾出的一块块建筑屋顶，森林是符号化的树冠群，河流是三条平行波线（中间那条最粗）——这和真实地图上的"晕滃"制图法（Lehmann 1799 那套）同源：**山不用画，山的体积全压在线的密度和方向里**。这正好接上库里 11-09 的《晕滃法》那条——但**那一条讲的是"纯墨线造地形、不用颜色"，本条是"墨线画好之后再手填颜色"，落点在"手工上色"这一步**。
  - **技法来源**：纽伦堡的 Johann Baptist Homann（1664–1724），1702 年在纽伦堡开制图工坊，十年内成为德语区最大地图出版商，1715 年被神圣罗马皇帝任命为"帝国制图师"（Reichsgeograph）；死后由子嗣以 **Homann Heben / Homann Erben（Homann 遗属）** 之名延续。另一条源流是 18 世纪英国 / 法国的**手绘地籍图**（cadastral map）：铁笔（pen-and-ink）直接画在纸上再手工上色，Libre 藏有一批 1750–1789 的北美殖民地地籍图，ARGO 档案里明确标注 "Manuscript, pen-and-ink and watercolor"。**一个卖印刷地图，一个卖纯手绘地图，但上色的手是同一双手。**
  - **与库内近义项显式错开**：与 11-09 **晕滃法 / 山体晕滃线** 是"同源不同工"——那一条是纯黑白墨线造地形，本条多了手工上色这一步；与 09-17 **马戏团彩色石版海报**（Strobridge 六至八块石版套印，机械套色）是"手 vs 机"——那一条是印刷厂套版，颜色必然对齐；本条是逐张手填，颜色必然**不对齐**，这是核心反差。与 10-16 **Photogravure 照相铜版** 同为铜版但一为凹版照片、一为凸版线画地图；与 09-18 Woodburytype（无网点连续调转印）也不是一路。
