# 奚叔阅读

我所收集和创建的阅读内容集合，用报纸版式把系列内容排成可以慢慢读的页面。

线上地址：<https://reading.xishu2099.top>

## 特性

- **报纸版式首页**：报头、导读条、主推文章、要目、三栏近期版面
- **沉浸阅读**：阅读进度、目录高亮、字号切换、夜读模式、续读记忆、已读标记
- **系列聚合**：每个系列有独立入口，按时间倒序排列，支持同系列上下期
- **纯静态生成**：无前端框架、无 CDN 依赖，构建产物直接部署
- **打印友好**：自带 `@media print` 样式，可直接打印成纸质版面
